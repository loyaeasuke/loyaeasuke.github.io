# 魔道書大戦RPG マギカロギア 角色資料庫（初版雛形）

沿用「角色資料庫網頁設計與CSV管理系統」的骨架：**左清單／右詳情**、預設是**縮圖展示頁**、用 **CSV 建立資料庫**、圖片用 **CSV 路徑指定**、可指定**角色代表色**自動套色、能匯出**純檢視網頁**。
本版依你的需求：**資料拆成多個 CSV 資料庫並互相 join、拿掉雷達圖、錨點關係的命運／屬性做成下拉式選單**。全站文字最小 13px，所有字級以此為基準往上排。

網頁標題：**魔道書大戦 魔法師名冊**。工具檔名：`magica-logia-mage-roster.html`。

---

## 檔案結構

```
magica-logia-mage-roster.html   主工具（開檔即見兩名示範角色，不必先載入）
魔法師名冊資料庫/
 ├─ 角色.csv          角色主檔（一列一名角色）
 ├─ 特技.csv          特技資料庫（6 領域 × 11 特技，含領域與骰值）
 ├─ 經歷.csv          經歷資料庫（名稱／說明／常見信條）
 ├─ 機關.csv          機關資料庫（名稱／說明／常見信條）
 ├─ 真實之姿.csv      真實之姿資料庫（名稱／效果／說明）
 ├─ 藏書_魔法.csv     魔法資料庫（魔法名／種類／指定特技／COST／效果）
 ├─ 錨點關係.csv      錨點關係資料庫（依角色 join；命運／屬性為受限值）
 └─ images/           頭像、全身圖、差分（CSV 用 images/xxx.png 相對路徑指定）
示範_純檢視版.html    匯出後的成品範例（無任何按鈕，純瀏覽）
```

## 使用流程

1. 直接用瀏覽器打開 `magica-logia-mage-roster.html`，即可看到內建示範（明星紫名＋一名範例角色）。
2. 按 **下載 CSV 範本** 取得整包 `魔法師名冊資料庫.zip`（含 7 個 CSV 與 images 說明）。解壓後用 Excel／試算表／記事本編輯，**務必存成 UTF-8**。
3. 編輯完成後，按 **載入資料夾**，選整個 `魔法師名冊資料庫` 資料夾——工具會一次讀入所有 CSV 與 images 圖片並比對路徑。
4. 預設是縮圖展示頁：依 `分類` 分組，每張卡＝頭像＋偽名（代表色）＋拼音＋魔法名。點任一張進詳情頁，效果同左側清單。左上「回到縮圖展示頁」返回。搜尋框同時篩選清單與展示頁。
5. 按 **匯出純檢視網頁** 得到一份無按鈕的成品 HTML。勾 **匯出時內嵌圖片** 會把圖片轉成 data URL 包進單一檔案（需先「載入資料夾」拿到原圖）；不勾則保留相對路徑，要跟 images 一起搬。

## 各 CSV 資料庫欄位

### 角色.csv（主檔，一列一名角色）
以「名稱」去 join 其他資料庫。多列欄位（習得特技）在儲存格內換行分列（Excel＝Alt+Enter、Google 試算表＝Ctrl+Enter）。

| 欄位 | 說明 |
|---|---|
| `分類` | 縮圖展示頁／側欄的分組依據（示範用所屬機關）。 |
| `偽名` `拼音` `魔法名` | 偽名為主顯示名兼 join 鍵；魔法名可用 `／` 分隔日文與中譯。 |
| `PL` `代表色` | 代表色填 `#9280A4` 這類色碼，會套用到名字、標題、標籤、特技表點亮等。 |
| `頭像` `全身圖` `差分` | 圖片網址或 `images/xxx.png`；差分多張用 `\|` 分隔，可點放大。抓不到時顯示名字首字色塊，不破圖。 |
| `性別` `年齡` `階梯數` `階梯名` | 基本資料。 |
| `攻擊力` `防禦力` `根源力` `魔力` `臨時魔力` `最大值` `功績點` | 數值。攻／防／根源顯示為大數字。 |
| `經歷` `經歷信條` `機關` `機關信條` `表面身分` | 經歷／機關填名稱，會 join 對應 CSV 帶出說明；信條為該角色所選文字。 |
| `領域` `判定特技` | 判定特技會在特技表標記（角落三角＋外框）。 |
| `魂之特技` `魂之特技判定` `魂之特技備註` | 魂之特技名、判定值、備註（如「魔力1消費」）；無則填 `無` 或留空。 |
| `習得特技` | **多列**，每列一項，格式 `特技:判定值:Gap1:Gap2`（Gap 欄填任意值代表勾選、留空代表未勾）。會在特技表點亮並列出判定值。 |
| `真實之姿` | 填名稱，join `真實之姿.csv` 帶出效果與說明。 |
| `個性` `義務對象` `義務願望` | 純文字。 |
| `藏書` | 魔法名清單，用 `\|` 分隔，join `藏書_魔法.csv` 帶出完整資料；查無會提示名稱不一致。 |
| `初期背景設定` `追加設定` `台詞` | 純文字，可換行。 |

### 特技.csv（含領域）
`領域,骰值,特技名`。內建完整 6 領域（星／獸／力／歌／夢／闇）× 11 特技（骰值 2〜12）。可自行修改特技名或領域，特技表會依此重繪。

### 經歷.csv／機關.csv
`經歷名,說明,常見信條`（機關同結構）。角色卡的信條沿用角色自己填的值；此處說明會顯示在詳情頁，常見信條為填卡參考。

### 真實之姿.csv（含效果）
`名稱,效果,說明`。角色 `真實之姿` 欄填名稱即 join。

### 藏書_魔法.csv
`魔法名,種類,指定特技,COST,效果`。這是共用魔法庫——多名角色可引用同一魔法，只需在此寫一次。

### 錨點關係.csv（命運／屬性下拉）
`角色,錨點名,命運,屬性,設定`，以 `角色`（＝偽名）join。
- **命運** 受限值：`1`、`2`、`3`、`4`、`5`、`創傷`
- **屬性** 受限值：`血緣`、`支配`、`宿敵`、`戀愛`、`興趣`、`尊敬`

詳情頁的錨點區可直接 **＋ 新增錨點**：命運與屬性是**下拉式選單**（就是上面兩組值），也能刪除既有錨點。這些在頁面上的增刪會即時反映，並在 **下載 CSV 範本／匯出純檢視網頁** 時一併寫回，方便你邊看邊調再輸出。

> 特技表的 6×11 名稱來自 `特技.csv`；判定特技以角落三角＋外框標記，習得特技以代表色點亮，Gap 以左上小圓點標記。

## 這是初版雛形

先把「上一版骨架＋多 CSV 資料庫＋錨點下拉」搭起來給你試。試用與試作資料後可再指定方向，例如：
- 網頁上直接新增／編輯整名角色（目前只做了錨點的下拉編輯）
- 疵（各領域）標記、Gap 連線視覺化、魔素充能圈
- 魔法使經歷表（多劇本：獲得／消耗／剩餘功績點）
- 義務、備忘區等欄位的呈現
- 資料包 ZIP 的「匯入」往返（目前匯入走「載入資料夾」）
