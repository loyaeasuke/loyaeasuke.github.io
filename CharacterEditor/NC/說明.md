# 神貓卓永い後日談のネクロニカ人偶名冊編輯器 — 使用說明

## 檔案結構

```
NC角色資料庫/
├─ nechronica-doll-archive-editor.html          ← 主工具（編輯器，已移除內建範例，開檔為空白）
├─ nechronica-doll-archive-viewer-sample.html   ← 純檢視範例（含露易絲／涅可示範，展示檢視版樣子）
├─ 說明.md
└─ 資料庫/
   ├─ 角色.csv               ← 人偶主資料（一列一名）
   ├─ 部件.csv               ← 部件目錄（含 スキル）
   ├─ 技能.csv               ← 傾向／類型專屬技能（與部件獨立）
   ├─ 暗示.csv
   ├─ 傾向.csv
   ├─ 類型.csv               ← 主要／輔助類型共用
   ├─ 記憶碎片.csv
   ├─ 死後經歷.csv
   ├─ 依戀內容.csv
   ├─ 寵愛點消耗.csv
   └─ images/                ← 立繪、頭像
```

## 使用流程

1. 用 Excel／Google 試算表／記事本編輯 `資料庫/` 裡的 CSV（**務必存成 UTF-8**）。
2. 瀏覽器打開 `nechronica-doll-archive-editor.html`（主工具已移除內建範例，開檔是空白，需自行載入資料）。
3. 按 **載入資料庫資料夾** → 選 `資料庫/`，工具會自動抓齊全部 CSV 與 images。
   （只想換角色資料時，也可用 **只載入角色 CSV**。）
4. 預設是縮圖展示頁，點任一人偶進詳情頁；左側清單、搜尋、回展示頁與前作相同。
5. 按 **匯出純檢視網頁**，得到一份沒有任何按鈕的成品 HTML。勾 **匯出時內嵌圖片** 可把圖片轉 base64 包進單一檔案（需先載入資料夾才拿得到原圖）；不勾則用相對路徑，要跟 `images/` 一起搬。
6. 按 **匯出編輯器（含資料庫）**，會把目前載入的參照資料庫（部件／暗示／傾向／類型／記憶碎片／死後經歷／依戀內容／寵愛點消耗／技能，含圖片）打包成一份「免載入資料庫」的編輯器；此打包**不含角色資料**（角色欄留白），方便把設定好的資料庫發給別人直接新增角色。

## 功能說明

**版面（檢視／編輯一致）**：檢視頁左欄＝人偶設計圖＋死後經歷＋記憶碎片＋依戀＋劇本經歷；右欄＝基本資料＋強化值·最大行動值＋外貌與個性＋Karma＋各部件（技能/頭/手/軀幹/腳）。編輯器採相同左右配置，所見即所編。

**行動值**：行動值 A＝基礎行動值，固定 6、不可改；行動值 B＝部件加成，自動計算、不可直接改。B ＝角色實際擁有、且未損傷部件的「最大行動值補正」總和（部件.csv 新增欄位，見下）。編輯器與檢視頁都會即時反映。

**部件「使用／損傷」**：檢視頁每個部件列有兩個核取方塊。「使用」只是臨時勾選、不保存；「損傷」勾了該列變紅、代表部件已壞，且會即時把 B 扣掉該部件的補正。損傷狀態會存進記憶體（部件名稱後加 `*`），匯出角色 CSV 時一起帶出；編輯器裡每個部件標籤也有「損」開關。

**攻擊判定值**：編輯模式改為唯讀顯示（不可改），沿用原本的頭/手/軀幹/腳判定值。

**人偶設計圖**：改為維持原圖比例、置中，不放大到滿版；1:1 的圖就以 1:1 呈現，只有超出欄寬時才等比縮小。

**名冊名稱**：工具列「名冊名稱」欄可改網頁名稱（預設「您的人偶名冊」），會同步側欄標題、瀏覽器分頁名稱、縮圖頁大標，並寫進匯出的純檢視網頁。

**匯出時機**：改成可連續編輯多名角色後、於工具列按「匯出角色 CSV」一次匯出全部；此鈕在「＋新增角色」右方。編輯器裡只保留「取消／套用並預覽」。

## 最大行動值補正（部件.csv 新欄位）

`部件.csv` 新增一欄 **最大行動值補正**（純數字，預設 0）。行動值 B 就是把角色擁有、未損傷部件的這欄加總。

> 為什麼用「手動欄位」而不是「自動解析效果文字」？因為有些效果字面上含「最大行動值+N」卻是**條件觸發**、不該被動計入——例如「限制裝置」的效果是損傷時「可以當場宣告最大行動值+2」。若自動解析文字會把它誤加，露易絲的部件加成就會從正確的 +4（腦袋+2、眼球+1、獸耳+1）變成 +6。手動欄位語意明確、不會誤判，所以採手動欄位。填表時只要在被動提供最大行動值的部件填數字即可。

## 角色編輯器（在網頁裡編角色，匯出成角色 CSV）

除了直接編輯 CSV，也可以在工具裡用表單編角色，各參照庫欄位都有**可搜尋的下拉選單**：

- 工具列 **＋ 新增角色**：開空白編輯器。
- 詳情頁右上 **✎ 編輯這名人偶**：帶入現有資料編修。
- 編輯器底下三顆鈕：
  - **套用並預覽**：把這名角色套進目前名冊並跳到詳情頁（只在記憶體，未存檔）。
  - **匯出角色 CSV（另存）**：下載一份含全部角色的 `角色.csv`（UTF-8 帶 BOM）。**不會回寫**你載入的原始檔，請自行另存到 `資料庫/` 覆蓋舊檔。
  - **取消**：放棄本次編輯。

各下拉選單對應（都可打字搜尋）：

| 欄位 | 操作方式 |
| --- | --- |
| 部件（技能/頭/手/軀幹/腳） | 搜尋**名稱**點選加入；同區可重複加入（如兩個內臟），chip 可用 ◂ ▸ 排序、✕ 移除；下拉清單完整顯示部件效果（可換行）。**基本部件**固定、只能標損傷、不可增減或自訂；**強化部件／技能**可按 ✎ 自訂名稱與說明（留空＝資料庫預設），且不可重複選同一項目（四肢共用去重）。各部件區下方會顯示「尚可加入各等級強化部件數量」，額滿（0 個）以警示色標示 |
| 暗示 | **編號**（純數字輸入，自動抓取；打 7 會正規化成 07）＋**名稱**（可搜尋下拉）；改其一，另一自動帶入 |
| 傾向 | 名稱（可搜尋下拉） |
| 主要類型／輔助類型 | 名稱（可搜尋下拉，兩者共用類型庫） |
| 記憶碎片 | 每列＝**編號**（純數字自動抓取）＋**標題**（可搜尋下拉）；可按 ✎ 自訂名稱與內容（留空＝資料庫預設）；可加多列 |
| 依戀 | 每列＝對象＋**內容**（可搜尋下拉）＋狂氣點 |
| 寵愛點消耗 | 每列＝**項目**（可搜尋下拉，選了自動帶入消耗值）＋消耗 |

> 下拉選單／清單皆依 `資料庫/` 對應 CSV 的**原始列順序**呈現（不自動排序）；先用「載入資料庫資料夾」載入，選單才會有完整項目。

## 編碼規則（所有 CSV 共用）

- `|`　分隔「多筆項目」（如記憶碎片、部件清單、技能、Karma）。
- `^`　分隔「一筆項目內的子欄位」（如依戀＝對象^內容^狂氣點）。
- 部件／技能／記憶碎片單筆可再接下列標記：`^寶物`（自訂寶物部件）、`^n:文字`（自訂名稱／標題）、`^d:文字`（自訂說明／內容）、`*`（部件損傷；置於單筆最後）。自訂文字內的特殊符號會自動轉義。
- `\n`　文章內換行（外貌與個性、記憶內容等）。
- 內容含半形逗號或雙引號時，整格用半形雙引號包住。

## 各資料庫欄位

### 角色.csv（一列一名人偶）
| 欄位 | 說明 |
| --- | --- |
| `分類` | 側欄與展示頁的分組（如戰役名） |
| `人偶名稱`／`拼音` | `人偶名稱` 為主顯示大名；`拼音` 顯示在大名**上方**的小字（留空時仍保留該行高度，版面不位移） |
| `玩家名稱` | |
| `代表色` | 對應角色卡的「文字圈用色碼」，如 `#93799F`；驅動判定值徽章、非基本部件底色、標題色標 |
| `頭像`／`全身圖` | 圖片路徑（相對於 `images/`）；全身圖多張用 `\|` 分隔，檢視時可左右切換、點擊放大 |
| `享年` | |
| `暗示` | 填**編號**（如 `07`），工具去 `暗示.csv` 展開成「07-渴望」 |
| `傾向`／`主要類型`／`輔助類型` | 填**名稱**，工具去對應 CSV 補上原文 |
| `武裝加值`／`變異加值`／`改造加值` | 強化值的**手動加值**。強化值總和＝類型補正 ＋（強化選擇 +1）＋ 加值；`角色.csv` 不再有原始「武裝／變異／改造」欄 |
| `強化選擇` | `武裝`／`變異`／`改造` 三選一（或留空）；被選者的強化基礎自動 +1 |
| `初期配置` | 煉獄／花園／樂園 |
| `Karma` | 目標，多筆用 `\|`；新增角色時預設第一項為「取得記憶碎片」 |
| `外貌與個性` | 文字，`\n` 換行 |
| `死後經歷標題/編號/內容` | 有填才顯示；填編號自動抓資料庫，或自訂名稱＋內容 |
| `記憶碎片` | 每筆為 `編號`，可另接 `^n:自訂標題`、`^d:自訂內容`（留空＝資料庫預設）；多筆用 `\|` |
| `依戀` | 每筆 `對象^內容^狂氣點`，多筆用 `\|`；發狂內容由 `依戀內容.csv` 帶入 |
| `頭判定/手判定/軀幹判定/腳判定` | 各部位攻擊判定值徽章（編輯模式唯讀） |
| `技能` | 每筆為技能名（對應 `技能.csv`），可另接 `^n:自訂名稱`、`^d:自訂說明`（留空＝資料庫預設）；不可重複選同一技能 |
| `頭部件/手部件/軀幹部件/腳部件` | 部件清單，每筆 `名稱`，可接 `^寶物`（自訂寶物）、`^n:自訂名稱`、`^d:自訂說明`、`*`（損傷）。**留空時自動帶入該部位所有基本部件**；新增角色預設：頭＝腦袋·眼球·齒顎、手＝拳頭·手腕·肩膀、軀幹＝脊椎·內臟·內臟、腳＝腳骨·腳骨·足。基本部件數量固定、不可增減，也不可自訂名稱／說明；同一強化部件不可跨部位重複選取 |
| `劇本經歷` | 每筆 `劇本名稱^故事經歷^獲得寵愛點` |
| `寵愛點消耗` | 每筆 `名稱^消耗`；說明由 `寵愛點消耗.csv` 帶入。總獲得＝各「劇本經歷」獲得寵愛點加總；剩餘＝總獲得 −Σ消耗，套用時自動計算 |

### 部件.csv
`部位,名稱,時機,COST,射程,效果,部件等級,最大行動值補正,說明`
- `部位` 可為 `頭/手/軀幹/腳/任意`（技能改由 `技能.csv` 管理）。
- **`任意` 部位**：標為 `任意` 的部件在 `頭`、`手`、`軀幹`、`腳` 四個部位的下拉清單皆可選用。
- **基本部件**＝ `部件等級` 欄填 `基本部件`（與角色卡一致）；工具據此判定白底。非基本部件顯示為代表色淡底。
- 同名部件（如兩個 `內臟`、兩個 `腳骨`）在目錄裡只需一筆；角色的部件清單重複列出即可顯示兩列。

#### 強化部件的取得數量（依「強化值」自動過濾／驗證）
非基本部件、非寶物的強化部件（`部件等級` 為 `等級１～３武裝／變異／改造部件`），可取得的數量依該類別的**強化值查表**決定，`頭／手／軀幹／腳` 四個部位**共用**同一份額度：

| 強化值 | 等級1 | 等級2 | 等級3 |
|---|---|---|---|
| 1 | 1 | – | – |
| 2 | 1 | 1 | – |
| 3 | 1 | 1 | 1 |
| 4 | 2 | 1 | 1 |
| 5 | 2 | 2 | 1 |
| 6 | 2 | 2 | 2 |
| 7 | 3 | 2 | 2 |
| 8 | 3 | 3 | 2 |
| 9 | 3 | 3 | 3 |

- **捨高就低**：一個高等空位可放較低等的部件（例如等級3的空位可改放一個等級2或等級1的部件；等級2的空位可改放等級1）。反之不行。
- **自動過濾**：編輯器的部件下拉會即時隱藏「已無空位」的強化部件（含四肢共用計算），無法選取。
- **超額警示**：若載入的角色或手動調整後超出額度，超額的部件會標紅並顯示「強化值不足，無法加入」；此時「套用並預覽」停用（滑鼠移上顯示需修改的欄位），改到符合規則後才能套用。
- 武裝／變異／改造三類規則完全相同，各自獨立計算。
