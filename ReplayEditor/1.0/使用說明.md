# 神貓卓團錄編輯器 ─ 使用說明

## 檔案

| 檔案 | 用途 |
|---|---|
| `log_viewer.html` | 閱讀／編輯用頁面，直接雙擊開啟即可 |
| `log.csv` | 對話資料，可用 Excel／Google 試算表編輯或增行 |
| `speakers.csv` | 發言人設定，指定頭像圖片與代表色 |
| `pcs.csv` | PC（調查員）資訊，顯示在團錄開頭的可摺疊區塊 |

## 新的一場團
開啟 `log_viewer.html` → 按「讀取原始 LOG.html」選擇 ccfolia 匯出的原始檔 →
自動判讀標籤、發言人、代表色、擲骰與段落分隔，畫面立刻套用新內容，
同時下載整理好的 `log.csv` 與 `speakers.csv`（瀏覽器可能會問是否允許一次下載多個檔案，選允許）。
若目前已設定過頭像，同名發言人的頭像與顯示名稱會自動沿用。

編輯流程：改 CSV → 開啟 `log_viewer.html` → 按「載入 log.csv」「載入 speakers.csv」→ 畫面即時更新。
在頁面上改完頭像後，按「匯出 speakers.csv」可把設定存回檔案。
PC 資訊同理：改 `pcs.csv` → 按「載入 pcs.csv」套用；頁面上的 PC 區塊可整區收合，每張 PC 卡也能單獨收合。

定稿後按「匯出成 HTML」，會下載一份閱讀版 `劇本標題_日期.html`：資料已寫死在檔案裡，不需要 CSV，
且所有編輯介面（標題編輯、設定頭像、載入／匯出 CSV、匯出 HTML）都已移除，只保留篩選、搜尋、發言人下拉。
頁首的「共 N 行／M 位發言人」統計只在編輯版顯示，閱讀版只留下你設定的標題與副標題。
要再修改時回到 `log_viewer.html` 重新載入 CSV 即可。

## log.csv 欄位

| 欄位 | 說明 |
|---|---|
| 序號 | 排序用，可自由插入 1.5、2.5 之類的小數 |
| 類型 | `talk` 對話／`dice` 擲骰／`scene` 劇情段落／`info` 情報卡／`system` 數值變動／`title` 頁面標題／`end` 團務結束／`reward` 通關報酬／`note` 心得記錄／`battle_start` 戰鬥開始／`battle_end` 戰鬥結束／`epilogue_start` 後日談開始／`epilogue_end` 後日談結束／`prologue_start` 前日談開始／`prologue_end` 前日談結束／`round` 回合標示／`hidden` 隱藏資訊 |
| 頻道 | `main` 正劇／`other` 雜談／`info` 情報／`secret` 秘匿 |
| 秘匿對象 | 例：`秘匿(PL,KP)`，會顯示在名字右側 |
| 發言人 | 對應 `speakers.csv` 的「發言人」欄。留空則整行貼齊左側顯示 |
| 頭像 | 這一行專用的頭像網址。留空時就用 speakers.csv 的預設頭像；填了就只覆寫這一行 |
| 內容 | 對話本文。`類型=scene` 時這裡填段落標題（如「第二章　夜之街」） |
| 備註 | 自由欄位，不會顯示，給自己做標記用 |

### 標題列（類型 = title）
放在最前面的一列，用來設定頁首文字，不會出現在對話中：`內容` = 主標題、`備註` = 副標題（日期、KP 名等，可留空）、`秘匿對象` = 頂端英文小字。
也可以直接在 `log_viewer.html` 頁首點字修改（三行都能點），改完匯出 log.csv 就會寫回這一列。

### 團務結束（類型 = end）
整頁寬的粗細雙線收尾，中央顯示 `SESSION END` 與你填在 `內容` 的字（例如「劇本標題　完」）。`內容` 留空就只有 SESSION END。

### 通關報酬（類型 = reward）
綠色雙框報酬卡，左上角有 `REWARD` 標記。`發言人` 欄是卡片標題（留空預設「通關報酬」），`內容` 是報酬明細，換行會保留，適合條列技能成長、獎勵點數、取得道具等。

### 戰鬥開始／結束（類型 = battle_start／battle_end）
標明接下來進入或離開戰鬥環節，用紅色橫幅（開始）與灰色橫幅（結束）呈現。**不會**推進 SCENE 編號，純粹是戰鬥區段的起訖標記。`內容` 可填自訂字（如「最終決戰」），留空則顯示預設的「戰鬥開始」「戰鬥結束」。

### 前日談開始／結束（類型 = prologue_start／prologue_end）
標明劇本本篇開始前的前日談段落起訖。樣式與後日談對稱（雙線橫幅＋❖ 花飾），但改用晨青色調以便區分本篇前後。不會推進 SCENE 編號。`內容` 可自訂（如「序幕・雨」），留空顯示預設「前日談開始」「前日談結束」。

### 隱藏資訊（類型 = hidden）
記錄團務進行當下玩家看不到的幕後情報（KP 手上的真相、預定的觸發條件、暗地判定結果等）。用深色反白條呈現，與淺色的一般 `system` 數值行形成明顯反差，讀者一眼就知道這是場外視角的資訊。`發言人` 欄可填署名，名字會自動套用 `speakers.csv` 的代表色（深色底上會自動提亮以維持可讀）；留空只顯示 HIDDEN 標記。`內容` 換行保留。

### 回合標示（類型 = round）
戰鬥等場合的回合分段，顯示為紅色圓角膠囊「第○回合」，兩側細線貫穿。不會推進 SCENE 編號。

`內容` 會自動解析出當前回合數：
- 含箭頭時取箭頭後的數字 → `回合 : 1 → 2` 顯示「第二回合」、`[ KP ] 回合數 : 0 → 1` 顯示「第一回合」
- 沒有箭頭時取第一個數字 → `3` 顯示「第三回合」
- 完全沒有數字時，就顯示 `內容` 原文

數字會轉成中文（第十回合、第二十五回合），膠囊右側另標 `ROUND 02` 便於快速掃視。用「讀取原始 LOG.html」轉檔時，含「回合」字樣的 system 行會自動判為此類型。

### 後日談開始／結束（類型 = epilogue_start／epilogue_end）
標明劇本本篇結束後的後日談段落起訖。採書卷風的柔和米色雙線橫幅（開始為上雙線＋❧、結束為下雙線＋❦），刻意與 `scene`（細線＋SCENE 編號）和 `end`（粗黑雙線 SESSION END）區隔，且**不會**推進 SCENE 編號。`內容` 可自訂（如「數年後」），留空顯示預設「後日談」「後日談　完」。

### 心得記錄（類型 = note）
放在整份記錄最後的玩家／GM 感想卡，左側有虛線書脊、`COMMENT` 標記。`發言人` 欄是署名（PC 名、「PL 心得」、「GM／KP 心得」等），`內容` 是心得本文，換行保留、以襯線字加寬行距呈現，方便閱讀長段感想。要幾張就加幾列。

新增一個劇情段落：加一列，`類型` 填 `scene`、`內容` 填標題，其他留空。
新增擲骰：`類型` 填 `dice`，`內容` 用 `技能名 (1D100<=70) ＞ 56 ＞ 成功` 格式，最後一段會自動上色（成功綠／失敗紅／決定性藍／致命深紅）。

## speakers.csv 欄位

| 欄位 | 說明 |
|---|---|
| 發言人 | 必須與 log.csv 的發言人完全一致 |
| 顯示名稱 | 畫面上顯示的名字，可改 |
| 頭像網址 | 這位發言人的**預設**頭像。圖片網址（https://…）或相對路徑（如 `avatars/檔名.png`）。留空則顯示代表色圓形字母 |
| 代表色 | 名字顏色，沿用原 LOG 的角色色 |

頭像用本機圖片時，把圖檔放在 html 旁邊的資料夾，網址欄填 `avatars/檔名.png`。

## pcs.csv 欄位（PC 資訊）

顯示在工具列下方、團錄開頭的「隊伍資訊」區塊。1～6 位都支援：1 位時單欄，2 位以上自動排成雙欄。整區可收合，每張 PC 卡也可個別收合，收合後仍看得到立繪縮圖、PC 名、PL、職業。

| 欄位 | 說明 |
|---|---|
| 序 | 排序用 |
| PC | 角色名（卡片標題） |
| PL | 玩家名 |
| 職業 | 職業／頭銜 |
| 年齡 | 年齡 |
| 性別 | 性別 |
| 立繪 | 全身立繪圖片網址或相對路徑。留空顯示提示框，可之後補上 |
| 數值 | 能力值區塊，**換行分行**。同一行內用空格或全形空格分隔多組「名稱 數值」（如 `HP 12　MP 9　SAN 49／94　DB 0`），也接受「名稱：數值」（如 `年收：600万`）。畫面會自動排成一顆顆數值標籤 |
| 技能 | 技能區塊，換行分行，每項寫「技能：數值」（如 `說服：45　心理學：50`），畫面排成藍色技能標籤 |
| 持有物品 | 隨身物品，純文字，換行保留 |
| 備註 | 其他補充，會另成一個 NOTE 區塊，可留空 |

在試算表編輯「數值」「技能」這類多行欄位時，儲存格內換行即可（Excel 用 Alt+Enter、Google 試算表用 Ctrl+Enter）；匯出時會自動加引號保留換行。

## 顯示規則

- **main**：左側黑色粗線，正常字級
- **other**：灰字、小一號、無左線，雜談一眼可略過
- **info**：米色情報卡＋襯線字
- **秘匿/秘密**：紫色斜紋底＋外框，連續同一組秘匿只在開頭蓋一次「秘匿」印記
- **擲骰**：等寬字綠框橫條，結果單獨標色
- **秘密頻道的擲骰**（類型 `dice` ＋ 頻道 `secret`）：改為紫色斜紋虛線橫條，開頭有「秘匿」標籤、結果前顯示對象；隱藏「秘匿」篩選時也會一起收起來
- **劇情段落**：整頁寬的分隔線＋SCENE 編號
- **團務結束**：上下雙線收尾＋SESSION END
- **戰鬥開始**：紅色斜紋橫幅，標記戰鬥區段開始
- **戰鬥結束**：灰色橫幅，標記戰鬥區段結束
- **前日談開始／結束**：晨青色雙線橫幅，標記本篇前的前日談段落
- **後日談開始／結束**：米色書卷風雙線橫幅，標記本篇後的後日談段落
- **回合標示**：紅色膠囊「第○回合」，兩側細線
- **隱藏資訊**：深色反白條＋HIDDEN 標記，標明玩家當下看不到的幕後情報
- **數值變動（system）**：靠左對齊的點線細條，左側顯示發言人名（自動對應代表色）
- `system` 與 `hidden` 的發言人欄留空時，若內容開頭是 `[ 名字 ]` 會自動辨識為發言人並上色，舊的 CSV 不必手動改
- **通關報酬**：綠色雙框卡片，明細換行保留
- **心得記錄**：紫紅色書脊卡片，襯線寬行距，署名在上、本文在下
- 頭像優先度：log.csv 該行的「頭像」欄 ＞ speakers.csv 的預設「頭像網址」。也就是同一位發言人平常用預設圖，個別行想換圖（例如換表情、換立繪）時，只要在該行「頭像」欄填網址即可
- 沒有發言人也沒有頭像時，該行仍會以整行形式顯示
