# NECRONICA 戰鬥流程輔助工具 — 使用說明

（永い後日談のネクロニカ / 神貓卓 GM 用戰場・流程・單位管理工具）

一個單一 HTML 檔的 GM 輔助工具，開瀏覽器即可使用，無需安裝、無需連網。用來在戰鬥中管理刻度時間軸、單位位置、部件損傷、行動值與 COST 計算，逐步檢核戰鬥流程，並可直接編輯／匯入／匯出角色資料。

主檔：`necronica-battle-tracker.html`

## 快速開始

1. 用瀏覽器開啟 `necronica-battle-tracker.html`。
2. 工具會預載兩名範例人偶（露易絲、涅可）。
3. 用「匯入角色 CSV」載入你自己的角色，或用「新增單位」手動建立敵方怪物／智慧體。
4. 在戰場上調整各單位的行動值與位置，於下方詳情勾選「使用／損傷」，或按「開啟編輯」增刪技能與部件。
5. 用左側流程檢驗逐階段推進；按「下一刻度」推進刻度，走到底會自動進入下一輪。

> 開啟時已內建一組範例單位（等同「角色範本.csv」，含人偶、智慧體、怪物與集團），可直接試用或按「刷新戰場」重置。
6. 隨時可用「匯出角色 CSV」保存目前所有單位資料，或用「檢視戰場資訊」開啟燈箱檢視戰況與歷史紀錄並可匯出。

> 全部資料只存在當前分頁的記憶體中，重新整理頁面會清空。要保存請用匯出功能。

## 畫面結構

畫面分為四大區塊：

```
┌───────────────────────────────────────────────────────────┐
│  上方工具列（標題 + 新增/匯入/匯出角色/載入資料庫/匯出戰場）      │
├───────────┬───────────────────────────────────────────────┤
│           │  戰場工具列（ROUND / 刻度 / 下一輪 / 下一刻度 / 刷新） │
│  左側      ├───────────────────────────────────────────────┤
│  戰鬥摘要   │  戰場：敵方單位 │   刻度時間軸格盤   │ 我方單位        │
│  流程檢驗   ├───────────═══ 可拖曳分隔條 ═══───────────────────┤
│  COST 計算 │  下方：單位詳情（我方/敵方分頁 + 技能/部件表 + 編輯）  │
└───────────┴───────────────────────────────────────────────┘
```

戰場區與下方詳情區之間有一條**可拖曳的分隔條**（游標會變成上下箭頭），往下拖可放大戰場、縮小詳情，反之亦然。

## 上方工具列

| 按鈕 | 功能 |
|------|------|
| **＋ 新增單位** | 手動建立我方人偶或敵方單位（怪物／智慧體），可設定名稱、代表色、初期位置、最大行動值。 |
| **匯入角色 CSV** | 載入 `角色.csv`，一次匯入多個單位（可含敵方）。匯入後會自動刷新戰場。 |
| **匯出角色 CSV** | 將目前戰場上所有單位輸出成一份可再匯入的 `角色.csv`（含編輯過的技能／部件與依戀）。UTF-8（含 BOM），Excel 可直接開啟。 |
| **載入資料庫資料夾** | 選一個資料夾，工具會辨識檔名含「部件／技能／依戀／傾向」的 CSV 並熱抽換資料庫；現有單位會依新資料庫重新對應。 |
| **檢視戰場資訊** | 開啟燈箱視窗，直接檢視①目前戰場各單位狀態，②**戰鬥流程紀錄**——每按一次「下一刻度／下一輪」，會記錄離開時該 ROUND／刻度的完整流程（行動階段→擲骰→裁判→傷害→本刻度 COST 計算），**逐刻度累積、不覆蓋**，並標明所屬 ROUND 與刻度（新到舊排列）。視窗內含「匯出為 .txt」按鈕可下載戰場資訊＋全部紀錄。（按「刷新戰場」會清空紀錄；戰鬥存檔亦包含紀錄。） |
| **打包編輯器（含資料庫）** | 匯出一份**內含目前資料庫的獨立 HTML 編輯器**：開啟即用、免再「載入資料庫資料夾」。打包內容為目前使用中的部件／技能／依戀／傾向資料庫，**不含角色資料**（開啟時場上為空）。打包後的編輯器本身**不含此「打包編輯器」按鈕**。 |
| **匯出戰鬥存檔** | 將目前戰鬥進度（ROUND、刻度、所有單位與其位置／行動值／損傷／使用勾選、流程與擲骰紀錄）存成 `.json`。 |
| **匯入戰鬥存檔** | 讀取先前的 `.json` 戰鬥存檔，**接續上次中斷的戰鬥**（會覆蓋目前場上內容）。 |

## 左側：戰鬥摘要與流程檢驗

### 戰鬥摘要
即時顯示目前我方單位與敵方單位的數量。

### 戰鬥流程檢驗
依 NECRONICA 回合結構排列的檢核清單，可逐項勾選以追蹤進度：

- **戰鬥最初**：進行戰鬥相關動作【自動】宣告
- **行動階段**：說明文字「可進行動作【行動】宣告」→ 核取「敵方宣告動作」「我方宣告動作」→ 核取「【行動】宣告結束」。
  - **行動值＝目前刻度**的單位會自動列在對應核取項下方（敵方在「敵方宣告動作」、我方在「我方宣告動作」），並顯示其已勾選、時機為【行動】的技能／部件（游標移上去可看效果提示）；沒有勾選任何項目則顯示「待機」。
  - 每個單位在行動階段**只能選擇一個【行動】**：若已勾選 A 行動再勾選 B 行動，A 會自動取消、只保留 B。
  - 選擇行動後，會出現**目標選擇**（可搜尋下拉）：我方單位列出敵方單位、敵方單位列出我方單位。
  - 勾選「【行動】宣告結束」後，各單位時機為【行動】的「使用」核取方塊會被鎖定，避免再更動宣告。
- **擲骰階段**：說明文字「進行動作判定」→ 自動列出本刻度有宣告行動的單位，各自提供「大成功／成功／失敗／大失敗」單選鈕供 GM 記錄擲骰結果（每個單位僅能選一項）→ 核取「動作判定處理完成」。
- **裁判階段**：說明文字「可進行動作【裁判】影響擲骰結果」→ 勾選「動作判定處理完成」後，列出各單位已勾選、時機為【裁判】的技能／部件（無則不列出）→ 核取「【裁判】宣告結束」後，鎖定各單位【裁判】時機的「使用」核取方塊。
- **傷害階段**：說明文字「NC 進行傷害計算（此階段扣除敵我單位 HP／部件）」與「可進行時機為【傷害】的動作，影響指定動作的傷害結果」→ 勾選「【裁判】宣告結束」後，列出擲骰為「大成功／成功」單位的傷害加總（依攻擊類型分項並顯示合計）→ 核取「【傷害】宣告結束」。
  - 每個「大成功／成功」攻擊方下方，會列出其**攻擊目標**的部件，可勾選本刻度要損傷的部件；標題顯示「（攻擊方）本刻度已指定 N / 傷害值 M」，其中 **N 只計入該攻擊方自己指定的部件**。
  - 若本刻度該攻擊方勾選的損傷部件**數量超過其傷害值**，會顯示紅色提示，要求修正為與傷害值相同的數量（未達傷害值不提示）。
  - **多名攻擊方指定同一目標時**：各攻擊方只計自己指定的部件；目標「已損壞」的部件會在每個攻擊方的清單中**同步顯示**（標示由誰指定並鎖定、不計入他人）。
  - **單位詳情表格**中勾選目標部件損傷屬「手動指定」，會在攻擊方清單中以「（詳情指定）」同步顯示，但**不計入任何攻擊方**的指定數；其他刻度的既有損傷則以「（既有）」標示，皆不可於攻擊方清單更動。
- **本刻度 COST 計算**：見下。

重置規則：
- 按「**下一輪**」或「**刷新戰場**」→ 流程勾選、擲骰結果與「**使用**」勾選都會重置。
- 按「**下一刻度**」→ 只重置流程勾選與擲骰結果；「使用」勾選**保留**（其 COST 已於本刻度扣除，不會於後續刻度重複扣除）。
- 若按「下一刻度」後因後續無單位可行動而**自動進入下一輪** → 流程勾選、擲骰結果與「使用」勾選都會重置。

### 本回合 COST 計算
依照各單位在下方詳情所勾選的「使用」項目，自動加總本回合 COST，並以
`現在行動值 − 本回合 COST = 剩餘行動值`
的格式分我方／敵方列出。

## 中央：戰場資訊

### 戰場工具列

| 元件 | 說明 |
|------|------|
| **ROUND** | 目前回合數，初始為 1。 |
| **刻度** | 目前指標刻度，等於場上所有單位中最高的行動值（於刷新／下一輪時重算）。 |
| **下一刻度 ▾** | 先套用待套用的最大行動值減少量，再**扣除本刻度尚未扣過的使用 COST**（現在行動值 − 本刻度COST），並重置流程勾選與擲骰結果（**保留**「使用」勾選）；接著將「刻度」指標下移到場上**次一個較低且仍可行動（>0）**的行動值。若已無更低的可行動刻度，或全部單位行動值皆在 0 以下，會**自動進入下一輪**（此時才一併清空「使用」勾選）。 |
| **下一輪 ▸** | 進入下一回合：每個單位行動值 = **現在行動值 ＋ 最大行動值**（COST 已於各刻度扣除，故此處不再扣 COST）；並清空「使用」勾選、重置流程與擲骰結果。 |
| **⟳ 刷新戰場** | 回到 ROUND 1、清除所有損傷／使用、單位回到初期位置、刻度重設為最高行動值。 |

### 刻度時間軸格盤

- 橫軸為**刻度**（由 20 遞減至 −5），縱軸為五個**位置帶**：
  `奈落（最深／最危險）→ 地獄 → 煉獄 → 花園 → 樂園（最淺／最安全）`。
- 目前「刻度」所在的欄會高亮顯示。
- **刻度 0 至 −5** 為紅色不可行動區；游標移到這些格子時，會即時浮出**黑底白字**的提示「不可行動的領域」，並隨游標移動。
- 每個單位以**頭像棋子**放置於（位置 × 行動值）的交會格；點擊棋子可在下方詳情選取該單位。棋子為 1:1 正方形，欄寬足夠時為 30px、較窄時自動縮為 25px，格盤永遠不會與左右兩側清單重疊（過寬時格盤內部水平捲動）。

### 敵方單位 / 我方單位清單（格盤左右兩側）

每張單位卡片的排版：

- 第一列：**單位頭像（1:1，30px；怪物亦顯示預設頭像）＋ 名稱**，右側附 ↑ ↓ 手動排序鈕（不自動排序）。
- 第二列：**頭、手、軀幹、腳**（未損傷部件數；怪物顯示「部件」總數）、**行動值**（可輸入）、**位置選單**。
- 敵方卡片會標示類型（**怪物／智慧體／集團**），且**不顯示發狂標籤**；「集團」的部件計數標示為「集團 N」。
- **我方**卡片在名稱下方顯示**傾向與主要／輔助類型**（範例：`愛麗絲 | 塔納托斯／塔納托斯`），對應敵方清單的「類型」。
- **我方**卡片在有依戀時，會顯示**每個依戀對象各一個發狂小標籤**（詳見〈發狂機制〉）。
- 當單位所有部件皆損傷時，卡片顯示「**完全解體**」狀態標籤（棋子亦轉為灰階並標示）。
- 兩側清單可各自獨立上下捲動。

## 下方：單位詳情與編輯

- **我方單位 / 敵方單位** 兩個分頁切換。
- 分頁下方是**單位名條（chips）**，點選可切換檢視的單位；每個名條右側有「×」可移除該單位。
- 詳情表格內容：
  - **技能**（人偶／智慧體）：名稱、時機、COST、射程、效果，附「使用」勾選。
  - **部件**：依頭／手／軀幹／腳分表（怪物為單一部件清單）。每列附「損傷」與「使用」勾選。
    - 勾選**損傷** → 戰場對應部位的部件數量 −1，並即時影響最大行動值（但現在行動值改於「下一刻度」時才刷新，見〈核心計算規則〉）。
    - 勾選**使用** → 該項 COST 計入本回合 COST 加總。
  - 欄寬：「損傷」「使用」為兩個中文字寬；「時機」「COST」「射程」為四個中文字寬。技能表保留空白的「損傷」欄以維持對齊。

### 編輯模式（開啟編輯 / 完成編輯）
詳情表頭右側有「**開啟編輯**」鈕。進入編輯模式後：

- 每個技能／部件列會出現「**刪除**」鈕。
- 每張表格底部會出現**新增列**：以**可搜尋的下拉式選單**輸入關鍵字即時篩選，點選項目（或按 Enter）即加入。
- 敵方與我方單位都可編輯（怪物只能編輯部件、無技能）。
- 所有變更**即時存入該單位資料**；按「完成編輯」離開編輯模式。搭配「匯出角色 CSV」即可永久保存。

## 核心計算規則

- **最大行動值（人偶／智慧體）**：
  `基礎行動值 6 ＋ 各未損傷部件的「最大行動值補正」總和 ＋ 各技能的「最大行動值」加成`。
  - 例：某角色為 5，裝上「最大行動值 = 2」的技能「女武神」後變為 7。
- **最大行動值（怪物）**：基礎行動值 **6** ＋ 各未損傷部件的「最大行動值補正」總和（隨部件補正累加）。
- **最大行動值（集團）**：採用**自訂值**（新增敵方單位時，只有類型為「集團」可自訂最大行動值）。
- **最大行動值（智慧體／人偶）**：基礎 6 ＋ 部件補正 ＋ 技能加成。
- **手動建立、無部件無技能的單位**：使用你在對話框或行動值欄輸入的數值。
- **本回合 COST**：所有勾選「使用」之技能／部件中，COST 為純數字者加總；標示「無」等非數字者以 0 計。
- **下一刻度行動值**：`（現在行動值 − 本刻度 COST）`。
- **下一輪行動值**：`現在行動值 ＋ 最大行動值`。
- 因此，從某輪最低刻度進入下一輪時，實際結果等同 `（現在行動值 − 本刻度 COST）＋ 最大行動值`；COST 不會重複扣除，也不會漏扣。
- **行動值刷新時機**：因損失部件或其他原因導致最大行動值減少時，**不會立即改變現在行動值**；累積的減少量會在**按「下一刻度」時**才套入現在行動值（只減不增）。此機制不會影響剛「進入下一輪」算出的行動值——進入下一輪後第一次按下一刻度不會把棋子重置回最大行動值，只會依規則推進刻度。
- **完全解體**：當一個「有部件」的單位其全部部件都被標記損傷時觸發（無部件的單位不會判定為解體）。

## 發狂機制

- 發狂以**依戀對象**為單位切換：我方單位在戰場卡片上，**每個依戀對象各有一個發狂小標籤**。未發狂時標籤顯示對象名稱，點擊即對該對象發狂，標籤變為「發狂中」。
- 將游標移到「發狂中」標籤或其下方的發狂說明時，會浮出提示小視窗顯示該**依戀對象的名稱**。
- 發狂時顯示的說明文字，讀取自 `依戀內容.csv` 中該依戀項目的「發狂內容」。
- 機制效果依發狂內容自動套用：
  - **依存**（發狂內容：「妳的最大行動值減少 2」）→ 自身最大行動值 −2。
  - **信賴**（發狂內容：「除了妳以外的所有姊妹，最大行動值減少 1」）→ **其他同陣營**單位最大行動值 −1（此「同陣營 −1」效果**僅限信賴**）。
- **敵方單位沒有發狂標籤。**

## CSV 檔案格式

所有 CSV 皆為 **UTF-8（建議含 BOM）**。多重值以直線 `|` 分隔；欄位內若需逗號請使用全形「，」。工具會自動忽略檔首 BOM。

### 角色 CSV（匯入／匯出）

| 欄位 | 說明 |
|------|------|
| `人偶名稱` | 單位名稱（必填）。 |
| `代表色` | 十六進位色碼，如 `#c0424f`。 |
| `頭像` | 圖片網址（可留空，留空則以代表色 + 首字顯示）。 |
| `傾向`、`主要類型`、`輔助類型` | 顯示用文字。 |
| `初期配置` | 奈落／地獄／煉獄／花園／樂園之一。 |
| `最大行動值` | 給「無部件」的怪物或無部件無技能單位使用的固定值；人偶／智慧體可留空由「6＋部件＋技能」計算，有部件的怪物則由「0＋部件補正」計算。 |
| `依戀` | 格式 `對象^類型^狂氣度`，多筆以 `\|` 分隔，如 `涅可^依存^3\|艾莉^憧憬^2`。 |
| `技能` | 技能名稱清單，以 `\|` 分隔（對應技能資料庫）。 |
| `頭部件`/`手部件`/`軀幹部件`/`腳部件` | 各部位部件名稱清單，以 `\|` 分隔。寶物等特殊項可加標籤：`名稱^標籤`（如 `黑曜石項鍊^寶物`）。 |
| `陣營` | `我方` 或 `敵方`（留空視為我方）。 |
| `敵方類型` | `怪物`、`智慧體` 或 `集團`（僅敵方需要）。`集團` 以 `最大行動值` 欄填入自訂值。 |
| `怪物部件` | 怪物用的單一部件清單，以 `\|` 分隔（怪物不分部位、無技能）。 |

> 「匯出角色 CSV」會依此格式輸出目前所有單位，可原樣再匯入（往返一致）。

### 資料庫 CSV（供「載入資料庫資料夾」熱抽換）

| 檔案 | 欄位 |
|------|------|
| **部件 CSV** | `部位, 名稱, 時機, COST, 射程, 效果, 部件等級, 最大行動值補正, 說明, 攻擊類型, 傷害`；`攻擊類型`＝肉體／白刃／射擊／砲擊，`傷害`為純數字（供傷害階段加總）。部件等級可用「惡意0.5／1／1.5／2／3／4的部件」標記敵方部件。 |
| **技能 CSV** | `類別, 所屬, 名稱, 時機, COST, 射程, 效果, 說明, 特化, 最大行動值` |
| **依戀內容 CSV** | `名稱, 發狂內容, 概述, 發狂, 發狂對白` |
| **傾向 CSV** | `名稱, 原文, 說明` |

- **技能 CSV 新增「最大行動值」欄位**：若某技能有提升最大行動值的效果，於此欄填入數值即會自動計入單位最大行動值（留空者，工具也會嘗試從「效果」文字中的「最大行動值＋N」自動解析）。
- 依戀的發狂效果與說明取自**依戀內容 CSV 的「發狂內容」**欄。
- 「載入資料庫資料夾」以**檔名是否含關鍵字**辨識（部件／技能／依戀／傾向），因此 `部件範本.csv`、`技能範本.csv` 等皆可被正確載入。

## 常見操作情境

- **匯入我方隊伍**：準備好角色 CSV → 匯入角色 CSV → 於戰場調整位置與行動值。
- **建立一隻怪物**：新增單位 → 陣營選「敵方」、類型選「怪物」→ 填最大行動值 → 開啟編輯增列部件。
- **臨場調整單位技能／部件**：選取單位 → 開啟編輯 → 於表格底部新增或按刪除 → 完成編輯 →（可選）匯出角色 CSV 保存。
- **推進一個刻度**：於下方詳情勾選各單位本刻度「使用」的技能／部件 → 按「下一刻度」；走到底會自動進入下一輪。
- **紀錄部件被打壞**：於下方詳情勾該部件「損傷」→ 最大行動值即時更新；現在行動值於下一刻度時刷新；全毀時顯示「完全解體」。
- **切換發狂**：在我方卡片點對應依戀對象的發狂標籤；效果依該依戀的發狂內容自動套用。
- **存檔／交接**：匯出角色 CSV（單位資料）、以「檢視戰場資訊」檢視並匯出戰況與流程紀錄，或用「匯出戰鬥存檔」保存完整進度。

## 注意事項與已知行為

- 資料僅存於瀏覽器分頁記憶體，**重新整理即清空**；請用匯出功能保存。
- 「刻度」在**刷新戰場／下一輪**時才重算；手動改單一單位行動值不會立即改變刻度指標。
- 現在行動值在「下一刻度」時才隨最大行動值變動而刷新（僅下修）。
- 匯入角色 CSV 為**附加**（不覆蓋現有單位），且匯入後會刷新戰場。
- 舊版角色 CSV（無「陣營」等新欄位）仍可匯入，會一律視為我方，向下相容。
- 若某部件／技能名稱在資料庫中找不到，欄位會標示「（資料庫無此部件／技能）」，可用「載入資料庫資料夾」補齊後自動重新對應。
- 敵方單位不提供發狂標籤；發狂為我方單位、以依戀對象為單位切換。
- **頭像圖片載入失敗**時不顯示破圖，改以底色＋名稱首字呈現。
- **我方單位不可加入部件等級含「惡意」的部件**；敵方單位可於新增部件的可搜尋下拉選單中，直接輸入「惡意」或部件名稱找到並加入。
- 沒有任何技能／部件的單位，在編輯模式下各表格仍會顯示可搜尋下拉選單以供新增。
- 新增部件的可搜尋下拉選單會**依部位自動過濾**：頭／手／軀幹／腳各表只列出該部位或「任意」的部件；「任意」部件可加入任何部位（怪物／集團的單一部件清單則不做部位過濾）。
- 新增單位時（我方，或敵方智慧體）可設定**傾向、主要類型、輔助類型**，這些會決定可新增哪些技能。
- 敵方「智慧體」可選擇**任何傾向／類型**的技能（不受下列過濾限制）。
- 技能的可搜尋下拉選單會**依傾向／類型自動過濾**：
  - 類別為「傾向」的技能，只有**傾向相符**的單位可加入。
  - 類別為「類型」的技能，**主要類型或輔助類型**其一相符即可加入。
  - 標記「特化」的技能，需**主要類型與輔助類型皆等於**該技能所屬（例：主＝輔＝迷幻人偶，才可選「毀滅風暴」）。
- 技能與部件的下拉選單都會**排除已加入過的項目**，不能重複加入。
- 發狂說明會同時顯示**發狂名稱**與**發狂內容**。
- 戰場棋子右上的發狂角標（「狂」）即使未被選取，也不會被右方格子遮住。
- 選取棋子時，對應的我方／敵方單位清單會自動滑動，使該單位卡片顯示在清單最上方（僅滑動、不改變排序；已接近清單底端者則滑到可捲動的極限）。位於「奈落」的單位，其選取邊框上緣也不會被刻度列遮擋。
- 「打包編輯器（含資料庫）」匯出的 HTML 為完整獨立檔，可離線、免載入資料庫直接使用（不含角色資料）。
- 「匯出／匯入戰鬥存檔」以 `.json` 保存全部戰鬥狀態，供跨次接續；匯入會覆蓋目前場上內容。
- 頭像圖片以**保持原圖全貌縮小**顯示（不裁切），空白處透明；建議使用接近 1:1 的方形圖片以獲得最佳效果。
- 全介面最小字級 13px；建議在桌面瀏覽器全螢幕使用，體驗最佳。
