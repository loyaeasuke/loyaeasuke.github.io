📚 書籤書架 — 使用說明

一個「書本風格」的網頁書籤整理工具：整本是一座書架，每個資料夾是一本小書，可一層一層點開瀏覽；每個書籤做成迷你瀏覽器卡片，有網址列與網頁縮圖，並能加標籤分類、搜尋篩選。單一 HTML 檔，雙擊即用，資料存在你的瀏覽器裡。

檔案

檔案用途
bookmark-book.html主程式，直接雙擊用瀏覽器開啟即可
bookmark-book-guide.html本說明
書籤書架備份.json你按「匯出 JSON」會下載的完整備份（含標籤、縮圖、分類）

介面導覽

  • 書架（最上層）：打開就是你的大書架。上方麵包屑 📚 書架 › 資料夾 › 子資料夾 顯示目前位置，點任一層可跳回。
  • 資料夾＝小書：每個分類是一本有書背顏色的小書，顯示名稱與項目數。點書身往下鑽一層；滑鼠移上去右上角會出現 ✎ 可編輯。
  • 書籤＝迷你瀏覽器卡：卡片上緣是網址列（favicon＋網址預覽），中間是網頁縮圖，下面是名稱與標籤，再下面有「開啟／編輯」。點縮圖、標題或「開啟」都會在新分頁打開該網址。
  • 右上角 🌙／☀️：切換深／淺色。

建立分類與書籤

新增資料夾

按右上角 ＋ 資料夾。填名稱、挑書背顏色、選「建立在」哪一層（預設是你目前所在的資料夾），儲存。資料夾可無限層巢狀。

新增書籤

按 ＋ 書籤。填名稱與網址即可；也可在這裡設縮圖與標籤、選所在資料夾。網址沒寫 http(s):// 會自動補上 https://。

編輯／移動／刪除

在卡片按「編輯」（或資料夾的 ✎）即可改內容。想搬移書籤或資料夾到別的分類，就在編輯視窗把「所在資料夾／建立在」改成目標位置再儲存。刪除資料夾會連同裡面的內容一起刪除（會先跳確認）。

網頁縮圖與網址列

  • 自動縮圖：沒有手動指定時，大縮圖會自動用 mShots 抓該網址的網頁截圖，網址列小圖示用 favicon。
  • 手動覆寫：在書籤「編輯」的「縮圖圖片網址」貼上任何圖片網址即可覆蓋自動截圖；留空則回到自動。編輯視窗左側會即時預覽。
  • 抓不到圖時：卡片會顯示「代表色＋名稱首字＋網域」的佔位圖，不會破版。
關於 mShots：第一次抓某個網址時，它可能先回一張灰色的「產生中」圖片；過幾秒後重新整理頁面（F5），就會換成真正的網頁截圖。這是該免費服務的正常行為。
想自己做／換縮圖？這些「給網址回圖片」的免費服務都可直接貼進「縮圖圖片網址」：
  • WordPress mShots：https://s.wordpress.com/mshots/v1/<網址>?w=440
  • thum.io：https://image.thum.io/get/width/440/<網址>
  • favicon：https://www.google.com/s2/favicons?domain=<網域>&sz=64
把 <網址> 換成你的頁面網址即可。也可以貼你自己上傳到圖床的圖片網址。

標籤、搜尋與篩選

  • 設定標籤：在書籤編輯的「標籤」欄，用逗號或空白分隔多個標籤（例：工具、參考、常用）。
  • 標籤篩選：上方標籤列點一下標籤即篩選；可複選，需同時符合所有選取的標籤（再點一次取消）。點卡片上的標籤也會直接用該標籤篩選。
  • 搜尋：搜尋框會比對整個書架的名稱、網址、標籤。有搜尋或篩選時會改以「平鋪結果」顯示（跨所有資料夾）；清空後回到一層層瀏覽。

匯入瀏覽器書籤

先從瀏覽器把書籤匯出成 HTML：

  • Chrome／Edge：書籤管理員（chrome://bookmarks）→ 右上角 ⋮ → 匯出書籤。
  • Firefox：管理所有書籤（Ctrl+Shift+O）→ 匯入及備份 → 匯出書籤為 HTML。

回到本工具，按 匯入 ▾：

選項行為
匯入書籤 HTML（加入目前書架）把檔案裡的資料夾與書籤加到你現有的書架最上層，不動既有內容
匯入書籤 HTML（取代全部）清空後以該檔重建（會先確認）
載入完整備份 JSON（取代全部）用之前匯出的 JSON 還原全部內容

資料夾階層會完整保留；Firefox 書籤帶的標籤（TAGS）也會一起匯入。

匯出與備份

格式說明
完整備份 JSON保留全部：分類、標籤、自訂縮圖。平常備份、跨電腦搬移就用這個。
書籤 HTML標準瀏覽器書籤格式，可回匯 Chrome／Firefox；但瀏覽器書籤格式不含自訂縮圖，所以縮圖不會帶過去（標籤會以 Firefox 的 TAGS 保留）。

資料怎麼存的

本工具把資料存在這台電腦、這個瀏覽器的 localStorage 裡，每次變動都自動儲存，下次打開同一個檔案就還在。

請定期匯出 JSON 備份。以下情況瀏覽器可能清掉 localStorage，造成資料遺失：清除瀏覽資料／網站資料、使用無痕視窗、換瀏覽器或換電腦、把 html 檔移到別的資料夾後用不同路徑開啟。養成「整理完就匯出一份 JSON」的習慣最保險。
