跑團行程管理 — 使用說明

一個單檔、可離線使用的 TRPG 團務行程工具。以四種檢視管理你的跑團紀錄與排程，資料可完整匯出、匯入為可編輯的 CSV。開檔即用，所有資料存在你自己的瀏覽器裡，不會上傳到任何地方。

快速開始

  1. 用瀏覽器（Chrome / Edge / Firefox 皆可）直接打開 trpg-schedule-manager.html。
  2. 開檔即為空白（不含任何範例資料）。用右上 「＋ 新增團務」 一筆筆建立，或用 「匯入匯出 → 載入資料夾／匯入單一 CSV」 匯入你的 團務.csv。
  3. 右上四個分頁鈕可隨時切換：月曆、清單、卡片庫、統計。

你的資料會自動存在這台電腦的這個瀏覽器中（localStorage）。換電腦、換瀏覽器或清除瀏覽資料就會不見，因此重要資料請用「匯出團務.csv」另外備份。

標題與年度會自動變化

  • 頁面標題固定為「該年度 + 跑團管理」（例：2026跑團管理），年度會跟著月曆目前所在的年份自動改變——把月曆往前翻到 2027 年，標題就變成「2027跑團管理」。
  • 統計頁也有 ‹ 年 › 可切換年份，切換時標題同步更新。
  • 因此不需要、也沒有手動輸入標題或年度的欄位。

四種檢視

月曆

依日期把每一場團排在月曆格子上，對應參考圖下方的「跑團日子」月曆。

  • 上方 ‹ › 切換月份，「今天」跳回當月。切到不同年份時，標題會自動更新。
  • 每格的團務卡片依序顯示 編號 → 團名 → 時間（編號、團名靠左，時間靠右，三者對齊同一高度），左側色條與外框代表系統（同系統同色，顏色可於「設定」自訂）。
  • 游標指上即時顯示完整資訊：把滑鼠移到任一團務上，會立刻（無延遲）跳出小提示窗，顯示「編號. 團名 · 系統 · 完整日期範圍 · 時間」——月曆格子放不下的完整日期與系統，都能在這裡一眼看到。
  • 跨日團會橫跨格子：當一場團跨到隔天（例：晚上 10:00 跑到凌晨 12:20），會以一整條橫幅從開始日的格子一路延伸到結束日的格子，並標示「下午10:00 → 上午12:20」（只顯示時間；完整日期請看上述滑鼠提示）。當日就結束的團只顯示開始時間。若一條橫幅跨過週末換行，會在上、下兩週各畫一段，續接的那段以 ↪ 標示。
  • 已完成的團會淡化、取消的團會加刪除線。
  • 點任一場團即可編輯。
  • 沒有填開始日期的團不會出現在月曆（但仍會在清單、卡片庫、統計中）。

清單

可排序、可篩選、可就地編輯的資料表，對應參考圖右側的「跑團日子」表格。

  • 欄位：編號、團名、系統、開始日期、開始時間、結束日期、結束時間、狀態、成員、使用角卡、本次團務數、備註。
  • 就地編輯：直接點任一欄位就能在表格內修改（日期是日期選擇器、時間欄一樣 2200→下午10:00）；按 Enter 或點別處儲存、Esc 取消。欄寬固定，編輯時不會跳動。「狀態」與「本次團務數」兩欄為自動計算、不可手動編輯。
  • 狀態自動判定：狀態依「結束日期」自動決定——未填結束日期＝預定、有填結束日期＝已完成。所以要把一場團標成「已完成」，只要填上它的結束日期即可（改結束日期時，狀態會立即跟著更新）。
  • 完整編輯視窗：若想一次改多個欄位，按每列最右操作欄的 ✎ 開啟編輯視窗（與「＋新增團務」相同的表單）。
  • 複製團務：按操作欄的 ⧉ 會把該列複製一份、插在它的正下方，方便快速建立同團的下一團次（複製後再改日期即可）。
  • 點欄位標題可依該欄排序，再點一次反向。
  • 上方可用關鍵字搜尋，並依系統、狀態（預定／已完成）、年份篩選。搜尋框有輸入內容時，右側會出現一個「✕」按鈕，點一下即可清空搜尋字（清單與卡片庫的搜尋框都有）。
  • 搜尋／篩選列與欄位標題列會固定在上方：往下捲動清單時，最上方的搜尋篩選列、操作提示文字、以及欄位標題（編號、團名…）都會釘在畫面頂端不動，方便對照欄位與隨時搜尋。

卡片庫

以團（一個劇本團）為單位的畫廊，對應參考圖左側的「2026 的團」。

  • 一團一張卡：相同「編號＋團名」的所有場次會合併成一張卡。你在清單建立團務、填好編號與團名，卡片庫就會自動出現對應的卡片（不需另外建立）。
  • 卡片的資訊由上到下：編號 → 共 N 團次 → 團名 → 日期範圍（第 1 團次的開始日 → 最後一次團次的結束日）→ 系統、使用角卡。若整個團所有場次都還沒填日期（全未定），團次會顯示「共 0 團次」（代表尚未實際排定任何團次）。
  • 卡片的狀態與清單的狀態不同：卡片狀態是整團的進度，由該團所有場次自動推導，只用來顯示——預定（場次全都還沒跑）、進行中（該團同時有已完成、也有還沒跑的場次，代表這個團正在進行中）、已結團（所有場次都已完成）。
  • 預設依編號由新到舊排列，可改依日期。另可勾選 「先依系統分組」：勾了會先把同系統的團排在一起，再依你選的編號／日期順序當第二層排序（系統與原排序同時套用）。
  • 上方可用關鍵字搜尋，並依系統、狀態、年份篩選（年份下拉與清單相同，只顯示該年有場次的團）。搜尋／篩選列會固定在上方，往下捲動卡片時不會跟著滑走。
  • 日期範圍固定顯示在同一行，不會因太長而換行（過長會以「…」收尾）。
  • 點卡片會跳到「清單」並自動篩出該團的所有場次。
  • 空白卡片：按卡片庫右上的 「＋ 空白卡片」 可新增一張虛線的空白占位卡（無標題、無編號、無日期）。空白卡片只出現在卡片庫、不會出現在清單與月曆，而且每張都獨立、不會互相合併。點空白卡片可開啟編輯視窗把它填成正式的團（填了團名/日期後就會出現在清單與月曆）。

統計

對應參考圖的「全年總計」，統計範圍是月曆目前所在的年度。

  • 所有數量都以「團」為單位：相同編號＋團名的多個場次算成一團，不會因為同一個團跑很多場次就重複計數（不再是計算清單的列數）。
  • 完成度環圈：該年度「已結團」團數 ÷「該年度總團數」。
  • 跨年度團務一律歸「開始年度」：一個團橫跨多個年度時（例如 2025 年開始、跨到 2026 才跑完），整團只會算在「最早場次所在的年度＝開始年度」，不會出現在後面的年度。所以一個 2025 年開始、跨到 2026 的團，只會計入 2025——就算它還沒結團、或延續到 2026，都不會算進 2026 的進行中／未結團，也不會出現在 2026 的月份分布（含年初）。整團狀態（預定／進行中／已結團）仍依所有年度的全部場次一起判定，只是套用在它的開始年度上：例如上例在 2025 年會顯示為「進行中」（有已完成也有還沒跑的場次），並列在 2025 年首場的月份。
  • 目標團數＝該年度總團數（去重後），系統自動計算，不需手動設定。
  • 總覽數字：總團數、已結團、進行中、預定、系統數；另有系統分布、月份分布（■ 已結團／未結）。以上皆依團計算。
  • 月份分布可查未結團：把游標移到月份分布圖的任一月份柱子上，會跳出提示小窗，列出該月尚未結團的團（編號＋團名），方便一眼看出哪些團還沒跑完。
  • 總覽數字可查團名（游標提示）：把游標移到「進行中」數字上，會列出當年度尚未結團（進行中）的團名；移到「預定」數字上，會列出當年度已有預定、尚未開始的團名（有下方虛底線者代表可查）。
  • 跨年度尚未結團提醒：由於跨年團一律歸「開始年度」，若有更早年度開始、卻還沒結團的團，會在「當年總覽」右方出現「⚠ 跨年度尚未結團」面板（例如看 2026 年時提示「2025 年 N 團」）；游標移上去即列出那些尚未結團的團名，避免忘了還有前一年沒跑完的團。
  • 參加次數統計（依系統）：把成員中的玩家與角色分開計次——成員格式為「角色名稱(玩家名稱)」，工具會排除主持職稱（預設 KP／GM／DL，可在「設定」增減，例如加入 SKP），其餘每位玩家、每個角色計次。以「團」為單位——相同編號＋團名的同一個團只計一次（同團跑很多場次不會重複累加）。每個系統一張卡（玩家、角色排行上下並列）。每張卡片為固定寬度、不會隨視窗拉伸，一行最多並排約 5～6 個系統，超過的系統會自動接續到下一行（視窗較窄時每列欄數自動減少）。
  • 「角卡使用」已併入參加次數統計（不再是獨立區塊）：「使用角卡」欄代表製作者用某張角色卡跑團，因此工具把它當成一筆參加紀錄併進來——
    • 製作者的名稱當作「玩家」計入玩家參加次數：若製作者名稱與成員中的玩家同名，次數會合併（使用幾次角色就累加幾次）。這個玩家會以特別顏色標示並加上 製作者 標籤。
    • 每張使用角卡當作「角色」計入角色參加次數：若角卡名稱與成員中的角色同名，次數會合併。這些角色會以 青色 標示（以顏色區分，不另加標籤）。
    • 兩種標色不同，方便一眼分辨哪個是製作者的名字、哪個是角色卡名稱。製作者名稱請在右上「設定」中設定。
  • 用 ‹ 年 › 可切換要看的年度。

新增與編輯團務

  • 右上**「＋ 新增團務」**開啟表單；或在任一檢視點既有的團來編輯。
  • 欄位說明：
    • 編號：該團的識別碼，可為數字或含字母（如 300、P40、K）。卡片庫依此排序。
    • 團名：一般團務請填；若全部留空則會存成卡片庫的「空白卡片」占位。
    • 系統：如 CoC克蘇魯的呼喚6th、InSANe。輸入時會自動提示你用過的系統。
    • 狀態：自動判定、不可手動更改——未填「結束日期」＝預定、有填「結束日期」＝已完成（編輯視窗中此欄唯讀，會隨你填的結束日期即時變化）。此為單場次狀態；卡片庫另有整團的「預定／進行中／已結團」狀態，由各場次推導，兩者不同。統計完成度只計「已完成」。
    • 本次團務數：自動計算、不需填寫。同一個團（相同編號＋團名）依日期由早到晚自動編成 1、2、3…（空白卡片不列入）。
    • 開始日期 / 開始時間、結束日期 / 結束時間：一場團的起訖時間。
    • 使用角卡、備註：選填。

時間輸入會自動格式化

  • 時間欄直接打數字就好：輸入 2200 離開欄位後會自動變成 下午10:00；925 → 上午9:25；110 → 上午1:10。
  • 也接受你直接輸入 22:00、下午10:00。

跨夜怎麼填

  • 結束日期留空 = 當日。若結束時間比開始時間早（例：開始 22:40、結束 01:10），系統會自動判定為跨到隔天凌晨。
  • 想明確一點，也可以直接把結束日期填成隔天。

系統代表色

每個系統在月曆、清單、卡片、統計裡都有一個代表色。

  • 預設是依系統名稱自動配色（同一個系統永遠同一色）。
  • 想自己指定：到右上**「設定 → 系統代表色」**，點該系統的色塊選色即可，會立刻套用到各檢視。
  • 按該列的 「自動」 可清除手動指定、恢復自動配色。
  • 手動指定的顏色存在你的瀏覽器裡，匯出「純檢視分享版」時也會一併帶入。

統計例外職稱

「參加次數統計」會把成員中的主持者排除，不計入玩家/角色參加次數。

  • 預設排除 KP／GM／DL（即成員寫成 KP(人名)、GM(人名)、DL(人名) 時視為主持者）。
  • 要新增例外（例如多了副主持 SKP）：到**「設定 → 統計例外職稱」**輸入 SKP 按新增即可；或編輯 例外.csv（欄位只有 職稱，一列一個）後匯回。
  • 例外清單存在你的瀏覽器裡，也可從「匯入匯出」下載 例外.csv 備份／編輯。

CSV 匯出與匯入

這是本工具的資料核心：所有團務資料都能匯出成 CSV、在 Excel／試算表編輯後再匯回。

團務.csv 欄位順序

空白範本（要自己填的欄位，右上「下載範本」即為此格式）：

編號, 團名, 系統, 開始日期, 開始時間, 結束日期, 結束時間, 成員, 使用角卡, 備註
  • 「狀態」與「本次團務數」不需填寫、也不在空白範本裡：兩者由工具自動判定（狀態＝有填結束日期就是已完成、否則預定；本次團務數＝同團依日期自動編號）。就算你匯入的檔案含有這兩欄，匯入後也會被自動重算。
  • 從本工具「下載」的完整 團務.csv 仍會包含這兩欄（方便備份與檢視），但匯回時它們一樣以自動判定為準。
  • 第一列為標題列。
  • 檔案編碼為 UTF-8（含 BOM），用 Excel 直接開不會亂碼。
  • 成員請用頓號 、 分隔，不要用逗號。
  • 日期建議 2026-09-28，也接受 2026/9/28、2026年9月28日。
  • 時間可填 2200、22:00 或 下午10:00，工具都讀得懂。
  • 結束日期留空＝預定（跨日曆顯示視為當日）、有填＝已完成；跨夜請把結束日期填成隔天。

操作位置（右上「匯入匯出」）

  • 載入資料夾：選一個資料夾，工具會自動抓裡面的 團務.csv 與 例外.csv。
  • 匯入單一 CSV：選擇或拖曳 團務.csv 或 例外.csv（依檔名／欄位自動判斷）。
  • 匯出：下載 團務.csv、例外.csv，或下載空白範本。
  • 注意：匯入團務會覆蓋目前所有團務資料（並非附加），匯入前若有未備份的資料請先匯出。

設定.csv（僅供備份，無法匯入）

  • 設定內容只有製作者、副標兩項，可從「匯入匯出」下載 設定.csv 做備份，但不支援匯入——若拖入 設定.csv，工具會忽略它。
  • 製作者請直接在右上「設定」中修改。副標為固定內容「使用神貓卓跑團管理手冊編輯器製作」，不可手動更改（設定頁中此欄唯讀顯示）。

純檢視分享版 HTML

「匯入匯出 → 純檢視分享版 HTML」會另存一個內嵌目前資料的 HTML 檔：移除所有編輯功能，只能瀏覽與切換檢視，適合直接傳給團友看（用瀏覽器打開即可，不需任何檔案或連線）。想更新內容時，回到本工具編輯後重新匯出即可。

常見問題

Q：資料會不會不見？ 資料存在你這台電腦的這個瀏覽器。清除瀏覽紀錄、換裝置都會消失，所以請定期用「匯出團務.csv」備份。

Q：目標團數怎麼設？ 不用設。它會自動等於「當年度的總團數」，你新增／刪除團時會自動更新。

Q：可以多人協作嗎？ 本工具是單機檔案。若要協作，建議把 團務.csv 放共用雲端資料夾，各自用本工具「載入資料夾」讀取、編輯後再匯出覆蓋。

Q：深色模式？ 右上月亮／太陽鈕可切換深／淺色，偏好會被記住。

本工具為單一自包含 HTML，可自由複製、分享、修改。
