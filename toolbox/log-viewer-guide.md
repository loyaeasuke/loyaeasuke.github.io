# 神貓卓團錄編輯器 ─ 使用說明

## 檔案

| 檔案 | 用途 |
|---|---|
| `log-viewer.html` | 閱讀／編輯用頁面，直接雙擊開啟即可 |
| `log.csv` | 對話資料，可用 Excel／Google 試算表編輯或增行 |
| `speakers.csv` | 發言人設定，指定頭像圖片與代表色 |
| `pcs.csv` | PC（調查員）資訊，顯示在團錄開頭的可摺疊區塊 |

## 新的一場團
開啟 `log-viewer.html` → 按「讀取原始 LOG.html」選擇 ccfolia 匯出的原始檔 →
自動判讀標籤、發言人、代表色、擲骰與段落分隔，畫面立刻套用新內容，
同時下載整理好的 `log.csv` 與 `speakers.csv`（瀏覽器可能會問是否允許一次下載多個檔案，選允許）。
若目前已設定過頭像，同名發言人的頭像與顯示名稱會自動沿用。

編輯流程：改 CSV → 開啟 `log-viewer.html` → 按「載入 log.csv」「載入 speakers.csv」→ 畫面即時更新。
在頁面上改完頭像後，按「匯出 speakers.csv」可把設定存回檔案。
PC 資訊同理：改 `pcs.csv` → 按「載入 pcs.csv」套用；頁面上的 PC 區塊可整區收合，每張 PC 卡也能單獨收合。

定稿後按「匯出成 HTML」，會下載一份閱讀版 `劇本標題_日期.html`：資料已寫死在檔案裡，不需要 CSV，
且所有編輯介面（標題編輯、設定頭像、載入／匯出 CSV、匯出 HTML）都已移除，只保留篩選、搜尋、發言人下拉。
頁首的「共 N 行／M 位發言人」統計只在編輯版顯示，閱讀版只留下你設定的標題與副標題。
要再修改時回到 `log-viewer.html` 重新載入 CSV 即可。

## log.csv 欄位

| 欄位 | 說明 |
|---|---|
| 序號 | 排序用，可自由插入 1.5、2.5 之類的小數 |
| 類型 | `talk` 對話／`dice` 擲骰／`scene` 劇情段落／`info` 情報卡／`system` 數值變動／`hidden` 隱藏資訊／`title` 頁面標題／`image` 圖片／`session_start` 團務開始（或 `start`）／`end`（或 `session_end`）團務結束／`reward` 通關報酬／`note` 心得記錄／`battle_start` 戰鬥開始／`battle_end` 戰鬥結束／`round` 回合標示／`turnorder` 行動順位／`madness` COC發狂／`epilogue_start` 後日談開始／`epilogue_end` 後日談結束／`prologue_start` 前日談開始／`prologue_end` 前日談結束／`message` 訊息／`telepathy` 心靈感應／`recall` 回憶／`chapter`（或 `chapter_start`）章節開始／`chapter_end` 章節結束 |
| 頻道 | `main` 正劇／`other` 雜談／`info` 情報／`secret` 秘匿／名稱含 `HO` 的頻道（如 `HO1`、`HOA`）＝秘匿手冊 |
| 秘匿對象 | 例：`秘匿(PL,KP)`，會顯示在名字右側。HO 頻道可留空，秘匿對象會自動等於頻道名 |
| 發言人 | 對應 `speakers.csv` 的「發言人」欄。留空則整行貼齊左側顯示 |
| 頭像 | 這一行專用的頭像網址。留空時就用 speakers.csv 的預設頭像；填了就只覆寫這一行 |
| 內容 | 對話本文。`類型=scene` 時這裡填段落標題（如「第二章　夜之街」） |
| 備註 | 自由欄位，不會顯示，給自己做標記用 |

### 標題列（類型 = title）
放在最前面的一列，用來設定頁首文字，不會出現在對話中：`內容` = 主標題、`備註` = 副標題（日期、KP 名等，可留空）、`秘匿對象` = 頂端英文小字。
也可以直接在 `log-viewer.html` 頁首點字修改（三行都能點），改完匯出 log.csv 就會寫回這一列。

主標題會自動配合長度縮放字級以維持一行：字少時用最大字級，字多到會換行時自動縮小（下限約 18px），視窗寬度改變時也會重新調整。

### 團務開始／結束（類型 = session_start／end）
一組成對的「書擋」：兩者共用相同的粗雙線外框與字體排版，一眼可看出是同一組起訖標記。差別在方向——開始用朝下的三角（▽，團務由此展開）配 `SESSION START`；結束用朝上的三角（△，收束上方內容）配 `SESSION END`。`內容` 可自訂（如「第二部・開始」「全劇終」），留空顯示預設「團務開始」「團務結束」。

團務結束的類型鍵是 `end`，也接受別名 `session_end`；團務開始是 `session_start`，也可簡寫為 `start`。（沿用舊 CSV 的 `end` 不需改動。）

### 通關報酬（類型 = reward）
綠色雙框報酬卡，左上角有 `REWARD` 標記。`發言人` 欄是卡片標題（留空預設「通關報酬」），`內容` 是報酬明細，換行會保留，適合條列技能成長、獎勵點數、取得道具等。

### 戰鬥開始／結束（類型 = battle_start／battle_end）
標明接下來進入或離開戰鬥環節，用紅色橫幅（開始）與灰色橫幅（結束）呈現。**不會**推進 SCENE 編號，純粹是戰鬥區段的起訖標記。`內容` 可填自訂字（如「最終決戰」），留空則顯示預設的「戰鬥開始」「戰鬥結束」。

### 心靈感應（類型 = telepathy）
與 message 相同的一對一／一對多訊息模式（分左右、頭像、合併、ruby、secret／HO 全部沿用，欄位填法與 message 完全一致），但樣式改為「腦內心聲」：無框的柔光橢圓泡泡、斜體、內容用 `⟨ ⟩` 包住，底色取發送者代表色拉往霧紫的低彩度柔光，和 message 的實體氣泡明顯不同。

### 回憶（類型 = recall）
顯示「回顧過去事件」的回憶段落。**連續多列 `recall` 視為一段**：第一列自動套起始樣式（泛黃淡入＋`RECALL 回憶`標記，若備註有填則顯示回憶標題），最後一列套結束樣式（泛黃淡出）；只有一列時頭尾合併。中間夾了任何非 `recall` 的列就中斷，之後的 recall 視為新的一段。

| 欄位 | 用途 |
|---|---|
| 類型 | `recall` |
| 發言人 | 有填＝對話式（頭像＋名字＋內文）；留空＝純敘述旁白 |
| 頻道 | `main`／空＝一般回憶對話；`secret`／`HO`＝回憶中的秘匿（紫色斜紋＋秘匿對象） |
| 內容 | 回憶內文（支援 ruby） |
| 備註 | **僅該段第一列**當回憶標題（留空則不顯示標題） |
| 秘匿對象／頭像 | 沿用 |

回憶內的對話式列若連續同發言人、同頻道、同秘匿對象仍會合併；純敘述列各自成段。此類型手動填寫，不列入目錄。

### 訊息（類型 = message）
角色之間傳訊息的聊天氣泡樣式（支援群組多人）。頭像＋名字＋氣泡，氣泡尖角指向頭像側，底色為發送者的刷淡代表色。

| 欄位 | 用途 |
|---|---|
| 發言人 | 發送者（取 speakers.csv 的頭像／顏色／顯示名） |
| 備註 | 靠邊：填 `R` 靠右；填 `L`、留空或其他一律靠左（預設 L）。靠右通常代表主視角／自己 |
| 秘匿對象 | 接收者（顯示成「→ 對方」，群組可填「→ 全體」等）。頻道為 secret／HO 時，同時就是秘匿對象 |
| 頻道 | 可用 `secret`／`HO`：氣泡改為紫色秘匿樣式並加「秘匿」標記；一般頻道則是普通聊天氣泡 |
| 內容 | 訊息本文（支援 ruby `((...))`） |
| 頭像 | 該行頭像覆寫（沿用），留空用預設 |

連續多則若**發送者、靠邊、頻道、接收者都相同**會合併成一串氣泡（頭像／名字顯示一次）。此類型需手動填寫，讀取原始 LOG 不會自動判斷；不列入目錄。

### 章節開始／結束（類型 = chapter／chapter_end）
戰役劇本進入下一段劇情時的章節標題，例如「一之章XXX」「二之章OOO」。章節開始用實心深色書卷帶（明顯比 scene 醒目，也和前／後日談的淺色雙線框不同）；章節結束用同形狀的描邊帶。`內容` 填章節標題。章節結束若**內容有填文字**就直接照原文顯示（例如自行填「一之章　邂逅　完」），**內容留空**才顯示預設的「完」。章節開始的類型鍵是 `chapter`，也接受 `chapter_start`。

章節開始會列入**目錄**（標示 CHAPTER，可點擊跳轉），且在目錄中加粗；章節結束不列入目錄。與 scene 一樣不影響 SCENE 編號。

### 前日談開始／結束（類型 = prologue_start／prologue_end）
標明劇本本篇開始前的前日談段落起訖。樣式與後日談對稱（雙線橫幅＋❖ 花飾），但改用晨青色調以便區分本篇前後。不會推進 SCENE 編號。`內容` 可自訂（如「序幕・雨」），留空顯示預設「前日談開始」「前日談結束」。

### 圖片（類型 = image）
插入 CG、地圖、道具圖等。圖片置中顯示，點擊後以燈箱檢視大圖（點畫面任一處或按 Esc 關閉）。
圖片網址填在「頭像」欄，圖說填在「內容」欄；若懶得分欄，也可只把網址填在「內容」欄（此時圖說取「發言人」欄，留空則無圖說）。網址無法載入時會顯示提示框，不會破版。

### 隱藏資訊（類型 = hidden）
記錄團務進行當下玩家看不到的幕後情報（KP 手上的真相、預定的觸發條件、暗地判定結果等）。用深色反白條呈現，與淺色的一般 `system` 數值行形成明顯反差，讀者一眼就知道這是場外視角的資訊。`發言人` 欄可填署名，名字會自動套用 `speakers.csv` 的代表色（深色底上會自動提亮以維持可讀）；留空只顯示 HIDDEN 標記。`內容` 換行保留。

### COC 發狂（類型 = madness）
克蘇魯神話 TRPG 中角色因 SAN 損失過多而發狂的記錄。以紫紅色斜紋卡片呈現，左上角 `SAN ↓` 標記，並依持續時間自動判為「短期發狂」或「長期發狂」，右側顯示持續時間膠囊，下方是發狂內容。角色名會自動套用 `speakers.csv` 的代表色。

在「內容」欄填一整串，格式為「角色名　發狂內容　持續時間」，用**全形空格**分隔（不用半形空格，因為角色名可能含半形空格如「源 秋良」）。持續時間放在最後、為「數字＋時間單位」（如 `5個月`、`1分鐘`、`14分鐘`、`6個月`），單位含分鐘／小時／秒／回合（判為短期）與天／週／月／個月／年（判為長期）。

用「讀取原始 LOG.html」轉檔時，**只有發言人是「KP」且訊息以持續時間結尾**的行會自動判為此類型；其他人講的、或 KP 沒有以時間結尾的話都不會被誤判。

### 行動順位（類型 = turnorder）
戰鬥中表示角色的行動先後。以圓角膠囊依序排出「① 名字 ▸ ② 名字 ▸ …」，左上角有 `TURN ORDER` 標記。
在「內容」欄**依序**填入角色名，分隔符可用「逗號（半／全形）、頓號、分號、換行」——**不要用空格**，因為角色名可能含半形空格（如「源 秋良」），空格不會被當成分隔。
「發言人」欄可填標題：有填就用它（如「第一場戰鬥行動順位」），留空則顯示預設「行動順位」。

### 回合標示（類型 = round）
戰鬥等場合的回合分段，顯示為紅色圓角膠囊「第○回合」，兩側細線貫穿。不會推進 SCENE 編號。

`內容` 會自動解析出當前回合數：
- 含箭頭時取箭頭後的數字 → `回合 : 1 → 2` 顯示「第二回合」、`[ KP ] 回合數 : 0 → 1` 顯示「第一回合」
- 沒有箭頭時取第一個數字 → `3` 顯示「第三回合」
- 完全沒有數字時，就顯示 `內容` 原文

數字會轉成中文（第十回合、第二十五回合），膠囊右側另標 `ROUND 02` 便於快速掃視。用「讀取原始 LOG.html」轉檔時，含「回合」字樣的 system 行會自動判為此類型。

### 後日談開始／結束（類型 = epilogue_start／epilogue_end）
標明劇本本篇結束後的後日談段落起訖。採書卷風的柔和米色雙線橫幅（開始為上雙線＋❧、結束為下雙線＋❦），刻意與 `scene`（細線＋SCENE 編號）和 `end`（粗黑雙線 SESSION END）區隔，且**不會**推進 SCENE 編號。`內容` 可自訂（如「數年後」），留空顯示預設「後日談」「後日談　完」。

### 心得記錄（類型 = note）
放在整份記錄最後的玩家／GM 感想卡，左側有虛線書脊、`COMMENT` 標記。`發言人` 欄是署名（PC 名、「PL 心得」、「GM／KP 心得」等），`內容` 是心得本文，換行保留、以襯線字加寬行距呈現，方便閱讀長段感想。要幾張就加幾列。

新增一個劇情段落：加一列，`類型` 填 `scene`、`內容` 填標題，其他留空。
新增擲骰：`類型` 填 `dice`，`內容` 用 `技能名 (1D100<=70) ＞ 56 ＞ 成功` 格式，最後一段會自動上色（成功綠／失敗紅／決定性藍／致命深紅）。

## speakers.csv 欄位

| 欄位 | 說明 |
|---|---|
| 發言人 | 必須與 log.csv 的發言人完全一致 |
| 顯示名稱 | 畫面上顯示的名字，可改 |
| 頭像網址 | 這位發言人的**預設**頭像。圖片網址（https://…）或相對路徑（如 `avatars/檔名.png`）。留空則顯示代表色圓形字母 |
| 代表色 | 名字顏色，沿用原 LOG 的角色色 |

頭像用本機圖片時，把圖檔放在 html 旁邊的資料夾，網址欄填 `avatars/檔名.png`。

## pcs.csv 欄位（PC 資訊）

顯示在工具列下方、團錄開頭的「隊伍資訊」區塊。1～6 位都支援：1 位時單欄，2 位以上自動排成雙欄。整區可收合，每張 PC 卡也可個別收合，收合後仍看得到立繪縮圖、PC 名、PL、職業。

| 欄位 | 說明 |
|---|---|
| 序 | 排序用 |
| PC | 角色名（卡片標題） |
| PL | 玩家名 |
| 職業 | 職業／頭銜 |
| 年齡 | 年齡 |
| 性別 | 性別 |
| 立繪 | 全身立繪圖片網址或相對路徑。留空顯示提示框，可之後補上。點擊立繪可開燈箱看大圖 |
| 數值 | 能力值區塊，**換行分行**。同一行內用空格或全形空格分隔多組「名稱 數值」（如 `HP 12　MP 9　SAN 49／94　DB 0`），也接受「名稱：數值」（如 `年收：600万`）。畫面會自動排成一顆顆數值標籤 |
| 技能 | 技能區塊，換行分行，每項寫「技能：數值」（如 `說服：45　心理學：50`），畫面排成藍色技能標籤 |
| 持有物品 | 隨身物品，純文字，換行保留 |
| 備註 | 其他補充，會另成一個 NOTE 區塊，可留空 |

在試算表編輯「數值」「技能」這類多行欄位時，儲存格內換行即可（Excel 用 Alt+Enter、Google 試算表用 Ctrl+Enter）；匯出時會自動加引號保留換行。

## 目錄

會自動依內容產生，不需要在 CSV 額外設定。收錄五種段落：章節開始（CHAPTER）、前日談（PROLOGUE）、每個劇情段落（SCENE）、通關報酬（REWARD）、每個後日談開始（AFTER STORY）。點任一項即可跳到該段落，捲動時會自動避開頂端的工具列。標題列可點擊收合整個目錄。

在較寬的視窗（1220px 以上）目錄會固定在畫面右側，上下捲動頁面時位置不動；視窗較窄時會自動回到 PC 資訊下方的一般位置，以免遮住團錄內容。項目數超過可視高度時，目錄內會出現捲軸，可上下拖拉檢視。

## 圖片建議尺寸與比例

所有圖片都吃網址（`https://…`）或相對路徑；本機圖片建議放在 html 旁的資料夾（如 `images/`、`avatars/`）再填相對路徑。

| 用途 | 欄位 | 比例 | 建議來源尺寸 | 備註 |
|---|---|---|---|---|
| 發言人頭像 | speakers.csv「頭像網址」、log.csv「頭像」 | 1:1 正方形 | 128×128 px | 會裁成圓形並填滿，臉部置中避免被邊緣切到 |
| PC 全身立繪 | pcs.csv「立繪」 | 3:5 直幅 | 600×1000 px（至少 450×750） | 佔位框為 3:5，適合全身圖。點擊可開燈箱看大圖，故建議來源放大以便放大檢視時清晰 |
| 圖片（CG／地圖／道具） | log.csv 的 `image` 列 | 不限（等比不裁切） | 長邊 1200–1600 px | 縮圖上限約寬 560px、高 60vh；點擊看大圖上限 96vw×92vh。橫幅 CG 約 16:9，地圖依原圖 |

尺寸只是建議值：頭像會自動縮放到顯示大小，給到約 2 倍解析度可讓高解析螢幕更清晰。PC 立繪與 `image` 圖片都可點擊開燈箱看大圖（燈箱上限 96vw×92vh），所以建議來源放大到能撐滿放大檢視的程度：立繪長邊約 1000px、圖片長邊 1200–1600px。給太大只會增加載入時間，過小放大則會模糊。

## 對話注音／別稱（ruby）

在對話類文字（`talk`／秘匿／HO／`hidden` 的內容）裡，可用 `((上方小字))` 在主文字上方標注別稱或拼音，效果類似日文振り仮名。段落標記、擲骰、數值等其他類型不解析此語法。

規則：每個 `((小字))` 會標注「它左邊、直到上一組 `((...))` 結束（或句首）為止」的那段主文字。

- **整句一條**：`從什麼時候回來的你總記得吧((いつ戻ってきたかぐらいは覚えてんだろ))` → 整句配一條上方小字。
- **逐詞多組**：`從什麼時候((いつ))回來((戻って))的你((きた))` → 各段分別注音。想切在哪就把 `((...))` 插在哪。
- **切刀 `(())`**：空的雙括號用來斷開前段且不注音。例：`這是所謂的(())禁忌((きんき))` → 只有「禁忌」被注上「きんき」，「這是所謂的」維持普通文字。
- 沒被 `((...))` 跟在後面的文字照常顯示。`((` 沒有對應 `))` 時整段當普通文字，不會出錯。

注意：目前不支援跳脫，若正文本身要顯示連續的 `((` 字面，請避免這種寫法。此語法需自行在 CSV 填寫，讀取原始 LOG.html 時不會自動產生。

## 相鄰同發言人合併

`talk`、`system`、`hidden`、`dice` 四種類型，若**連續多列是相同類型、相同發言人**，會自動合併成同一個區塊（頭像、名字只顯示一次），內容依序排成多個段落／多筆骰。talk 與 dice 另需**頻道相同**才合併（避免正劇與秘匿、一般骰與秘密骰混在一起）；頻道為 `secret` 時，還需**秘匿對象相同**才會合併（不同秘匿對象各自成區塊）。無發言人的列不參與合併。中間只要夾了其他列（別的類型、別的發言人等）就會斷開、各自獨立。

段落層次：合併的每一句之間是「段落間距」（類似 `<p>`）；單一句子內用換行（CSV 儲存格內換行）則是「行內斷行」（類似 `<br>`），兩者視覺上可區分。

## 顯示規則

- **main**：左側黑色粗線，正常字級
- **other**：灰字、小一號、無左線，雜談一眼可略過
- **info**：米色情報卡＋襯線字
- **秘匿/秘密**：紫色斜紋底＋外框，連續同一組秘匿只在開頭蓋一次「秘匿」印記
- **HO 頻道**（頻道名含 `HO` 且不是 `secret`）：套用與秘匿相同的樣式，秘匿對象自動帶入頻道名（如 `HO1`）；也一併受「秘匿」篩選與擲骰樣式規則管理
- 秘匿對話與秘密骰使用固定的紫色斜紋。只有 **message 的秘匿訊息**改用**發送者代表色**的斜紋（斜紋與邊框混入少許紫調，無代表色時退回紫色）；「秘匿」標籤本身一律維持紫色
- **擲骰**：等寬字綠框橫條，結果單獨標色
- **秘密頻道的擲骰**（類型 `dice` ＋ 頻道 `secret`）：改為紫色斜紋虛線橫條，開頭有「秘匿」標籤、結果前顯示對象；隱藏「秘匿」篩選時也會一起收起來
- **劇情段落**：整頁寬的分隔線＋SCENE 編號
- **團務開始／結束**：成對書擋，共用粗雙線外框；開始為 ▽＋SESSION START、結束為 △＋SESSION END
- **戰鬥開始**：紅色斜紋橫幅，標記戰鬥區段開始
- **戰鬥結束**：灰色橫幅，標記戰鬥區段結束
- **心靈感應（telepathy）**：無框柔光橢圓心聲泡泡，`⟨ ⟩` 包住、斜體、霧紫柔光，分左右
- **回憶（recall）**：泛黃褪色段落，連續 recall 自動頭尾淡入淡出，支援對話式與純敘述
- **訊息（message）**：聊天氣泡，發送者靠右（備註 R）或靠左，支援群組、秘匿氣泡與 ruby
- **章節開始／結束**：實心深色書卷帶（開始）／描邊帶（結束＋「完」），戰役章節標題
- **前日談開始／結束**：晨青色雙線橫幅，標記本篇前的前日談段落
- **後日談開始／結束**：米色書卷風雙線橫幅，標記本篇後的後日談段落
- **回合標示**：紅色膠囊「第○回合」，兩側細線
- **行動順位**：褐色膠囊依序排出角色行動順序（① ▸ ② ▸ …）
- **COC 發狂**：紫紅色斜紋卡片，短期／長期發狂標記＋持續時間，角色名套代表色
- **圖片**：置中縮圖，點擊開燈箱看大圖，可加圖說
- **隱藏資訊**：深色反白條＋HIDDEN 標記，標明玩家當下看不到的幕後情報
- **數值變動（system）**：靠左對齊的點線細條，左側顯示發言人名（自動對應代表色）
- `system` 與 `hidden` 的發言人欄留空時，若內容開頭是 `[ 名字 ]` 會自動辨識為發言人並上色，舊的 CSV 不必手動改
- **通關報酬**：綠色雙框卡片，明細換行保留
- **心得記錄**：紫紅色書脊卡片，襯線寬行距，署名在上、本文在下
- 頭像優先度：log.csv 該行的「頭像」欄 ＞ speakers.csv 的預設「頭像網址」。也就是同一位發言人平常用預設圖，個別行想換圖（例如換表情、換立繪）時，只要在該行「頭像」欄填網址即可
- 沒有發言人也沒有頭像時，該行仍會以整行形式顯示
