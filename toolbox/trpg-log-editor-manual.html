團錄清冊編輯器 使用說明書

對應檔案：trpg-log-editor.html 一個單一 HTML 檔的離線工具，用來建立分類式的「團錄清冊」（TRPG 團務紀錄目錄），為每篇團錄設定連結與防劇透緩衝頁，並可匯出成多種風格的純檢視網頁分享給團員。

這是什麼

trpg-log-editor.html 是一份可直接用瀏覽器開啟的編輯器。它本身不儲存團錄「內文」，而是幫你整理一份目錄清冊：左側是可分類、可摺疊的團錄清單，點選後右側會先顯示一頁防劇透緩衝頁（寫團務概要與防雷警告），確認後才載入你指定的團錄頁面（網址或本機相對路徑）。

編輯完成後，可以一鍵匯出一個獨立的純檢視版 HTML：資料直接烘進檔案、拿掉所有編輯功能，團員打開就能閱讀，且可挑選六種視覺風格。

  • 單檔、離線可用，無需安裝或帳號。
  • 資料存在瀏覽器本機（localStorage），並可用 CSV／JSON 匯出備份。
  • 全新開啟為空白，不含任何範例資料。

快速上手

  1. 用瀏覽器開啟 trpg-log-editor.html。
  2. 在最上方工具列的「網頁名稱」欄輸入這份清冊的名稱（例如你的桌名或系列名）。
  3. 點工具列的「分類編輯」新增至少一個分類（例如 CoC 201-250）。
  4. 點「團錄編輯」新增團錄：選分類、填連結名稱、指定連結（網址或相對路徑）、寫防劇透緩衝頁文字。
  5. 關掉視窗回到主畫面，點左側目錄的團錄→會先看到防劇透緩衝頁→按「翻開此頁」載入內容。
  6. 選好右上角「風格」後，按「匯出檢視版 HTML」下載給團員的純檢視檔。

建議一開始就用「匯入匯出 → 匯出 JSON 備份」養成備份習慣（見〈資料儲存與備份〉）。

介面總覽

頂端工具列

由左到右：

  • ◆ 團錄清冊編輯器：工具名稱。
  • 網頁名稱：自訂這份清冊的名稱，會即時同步到瀏覽器分頁標題，也會帶進匯出檔與檔名。
  • 團錄編輯 / 分類編輯 / 匯入匯出 / 資料設定：四個管理工具，點了會開啟對應的管理視窗（見〈管理團錄〉）。
  • 風格：選擇匯出檢視版要用的視覺風格，選擇時編輯器會即時預覽（見〈風格與即時預覽〉）。
  • 匯出檢視版 HTML：把目前清冊匯出成獨立的純檢視網頁。

左側目錄

  • 分類以分卷小標呈現，可點擊展開／收合，且各分類互不影響（可同時展開多個）。
  • 每則團錄顯示「序號 + 連結名稱」，版面採緊密排列。
  • 若有未指定分類的團錄，會在最下方自動出現「未分類」區塊。

右側內容區

  • 預設：顯示提示文字，請自左側選擇團錄。
  • 防劇透緩衝頁：顯示團錄標題、KP／PL、你寫的概要與防雷警告，以及「翻開此頁」按鈕。
  • 內容檢視：按下「翻開此頁」後才載入你指定的連結；上方有「返回緩衝頁」與「在新分頁開啟」。

名詞與資料結構

  • 網頁名稱：整份清冊的標題（工具列可改）。
  • 分類：目錄的分卷（例如 CoC 1-50）。可新增、改名、排序、刪除。
  • 團錄：一則團務紀錄的目錄項目，包含下列欄位。
  • 未分類：沒有指定分類（或其分類被刪除）的團錄，統一歸在目錄底部的「未分類」。

每則團錄的欄位：

欄位 說明
所屬分類 團錄歸屬的分類；可選「未分類」
連結名稱 左側目錄顯示的文字（例：219. 一室惡夢）
團錄標題 緩衝頁上的大標；留空則沿用「連結名稱」
KP 主持人（Keeper／GM），可留空
PL 玩家，可留空
指定連結 要載入的團錄頁面位址：完整網址或相對路徑
防劇透緩衝頁文字 進入內容前先顯示的概要與防雷警告，可換行
繼續角色 本次 PC 承接自哪個劇本的角色；選填，填了才會顯示在緩衝頁（防雷文字下方）

管理團錄（四個工具）

團錄編輯

新增與修改團錄。

  • 新增：填妥表單後按「新增團錄」。
  • 修改既有團錄：在下方清單點該列右側的鉛筆（✎），表單會切換為「編輯團錄：⋯」並帶入原本內容，改完按「儲存變更」即更新同一筆（不會產生重複）；旁邊有「取消編輯」。
  • 刪除：點該列的垃圾桶（🗑）。

分類編輯

  • 新增分類：輸入名稱後按「新增分類」。
  • 改名 / 上移 / 下移：以各列的按鈕操作，排序即左側目錄的顯示順序。
  • 刪除分類：會先確認；刪除後，該分類底下的團錄會自動移到「未分類」，不會消失。

匯入匯出

以 CSV 當作簡易資料庫，或做 JSON 完整備份。

CSV 欄位順序（第一列為標題列，會被略過）：

分類, 連結名稱, 標題, KP, PL, 連結網址, 防劇透文字, 繼續角色
  • 含逗號或換行的欄位，請用雙引號 "…" 包住（防雷文字常會需要）。
  • 最後一欄「繼續角色」為選填；舊的 7 欄 CSV 仍可正常匯入（該欄視為空白）。
  • 匯入會附加到現有資料；出現新的分類名稱會自動建立該分類。
  • 「分類」欄留空的資料會歸入未分類。
  • 可用「拖曳檔案／點選檔案」或直接「貼上 CSV 內容」兩種方式匯入。
  • 匯出 CSV：下載目前所有團錄（未分類的列，其分類欄為空）。
  • 匯出 JSON 備份 / 還原 JSON 備份：JSON 含分類與排序等完整資料；還原會覆蓋目前所有內容。

資料設定

  • 全部清空：刪除所有分類與團錄，無法復原（會先確認）。

指定連結：網址或相對路徑

「指定連結」不限定格式，兩種都可以：

  • 完整網址：https://example.com/logs/219
  • 相對路徑：219.html、logs/219.html、../其他資料夾/219.html

相對路徑會相對於網頁本身所在的位置解析。因此若使用相對路徑，請把這個編輯器檔案（或匯出的檢視版）與團錄頁面放在對得上的資料夾結構下再開啟。

提醒：以本機 file:// 直接雙擊開檔時，部分瀏覽器基於安全限制可能不允許 iframe 載入本機相對檔案；此時右側可能空白，改點「在新分頁開啟」即可。放在網頁伺服器（或同一站台）下則不受此限。

防劇透緩衝頁

點選團錄後，右側不會直接載入內容，而是先顯示一頁緩衝頁：團錄標題、KP／PL、你在「防劇透緩衝頁文字」寫的概要與防雷警告，以及「翻開此頁，顯示團錄內容」按鈕。

在按下按鈕之前，內容的 iframe 完全不會建立，因此是真正的防雷，不會偷偷預載頁面。標題過長時會自動縮小字級以維持單行顯示。

若團錄有填「繼續角色」，會顯示在防雷文字的下方（例如標註本次 PC 承接自哪個劇本）；未填則不顯示。

連結失效偵測

進入內容檢視時，會先顯示「載入中…」，失效提示預設不出現，只有在偵測到問題時才會跳出（醒目樣式），並提醒改用「在新分頁開啟」：

  • 相對路徑／同源頁面：可判讀是否為空白或 404／找不到，失效才提示。
  • 完全打不開／逾時（約 6 秒無回應）或錯誤：提示。
  • 跨網域外部網站：若對方以 X-Frame-Options／CSP 禁止被嵌入，瀏覽器基於安全不提供可靠訊號，程式無法判斷，因此不會誤報；此時以逾時為保底，右側若空白請用「在新分頁開啟」。

風格與即時預覽

右上角「風格」下拉可選六種視覺風格。所有風格版型相同（目錄一律在左側固定、寬度不變、保留序號欄與可摺疊分類），差別只在配色、字級、間距與按鈕樣式。

風格 特徵
帳冊 暖色紙面 × 牛血紅，襯線字，古籍帳冊感（預設）
紀事 清爽白底 × 靛紫，俐落現代
黑暗奇幻 深色皮革 × 金色微光，古老魔典感
都市恐怖 冷調近黑 × 血紅，無襯線、直角銳利
克蘇魯 深淵墨綠黑 × 磷光綠，副標斜體、綠色幽光
森林清新 淺米綠亮底 × 森綠，膠囊圓角、行距寬鬆

切換風格時，編輯器會即時套用該外觀（含最上方頂端列與所有按鈕），不用匯出就能確認效果。所選風格會被記住，下次開啟沿用。

匯出檢視版 HTML

按「匯出檢視版 HTML」會下載一個獨立、可離線的純檢視檔：

  • 資料直接烘進檔案，不依賴編輯器或外部資料。
  • 保留完整閱讀體驗：左側目錄、防劇透緩衝頁、內容檢視與失效偵測。
  • 拿掉所有編輯／匯入匯出功能，適合直接分享給團員。
  • 套用你所選的風格。
  • 目錄最下方固定顯示：「使用神貓卓團錄清冊編輯器匯出檢視」。
  • 檔名格式：{網頁名稱}-檢視版({風格}).html。

若團錄使用相對路徑，記得把匯出的檢視版檔案放在與團錄頁面對得上的資料夾結構下再開啟或上傳。

資料儲存與備份

  • 你的資料存在瀏覽器本機（localStorage），與「瀏覽器 + 檔案所在位置」綁定。
  • 請把 trpg-log-editor.html 固定放在同一個路徑／網址使用；更換位置、換瀏覽器或清除瀏覽資料，都可能讀不到先前的資料。
  • 養成用「匯出 JSON 備份」保存的習慣；需要時以「還原 JSON 備份」帶回。
  • 換裝置或搬移時，也可先在舊環境匯出 JSON，再到新環境還原。

疑難排解

  • 右側一片空白：多半是該網站禁止被 iframe 嵌入，或本機 file:// 限制。改點「在新分頁開啟」；相對路徑請確認檔案放在正確的資料夾結構、並透過伺服器或同站台開啟。
  • 看到舊的範例資料：可能是先前版本已把範例存進此瀏覽器。到「資料設定 → 全部清空」即可清乾淨。
  • CSV 匯入後防雷文字跑版：含逗號或換行的欄位務必用雙引號 "…" 包住。
  • 資料不見了：確認是否更換了檔案位置或清除了瀏覽器資料；用先前的 JSON 備份還原。
  • 標題被縮小：這是刻意設計——標題過長時會自動縮小以維持單行；可縮短「團錄標題」。
