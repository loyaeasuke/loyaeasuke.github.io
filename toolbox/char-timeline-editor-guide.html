紀年時間軸 char-timeline-editor 使用說明

一個單一檔案的橫向事件時間軸工具，用瀏覽器打開即可使用，適合角色／劇情紀年管理。所有資料存在網頁當下，請用 CSV 下載保存。

檔案

  • char-timeline-editor.html：主程式（可檢視也可編輯）。
  • char-timeline-view.html：由主程式「匯出檢視版」產生的唯讀網頁（無法編輯），適合分享或發布。
  • char-timeline-editor-guide.md：本說明。

如何開啟

在 char-timeline-editor.html 上點兩下，即以預設瀏覽器開啟；或右鍵選擇用 Chrome／Edge／Safari 開啟。首次開啟需連網（載入 React、字型等元件）。

自訂網頁名稱

  • 左上角的主標題本身就是可輸入的欄位，直接點擊即可修改，預設為「紀年時間軸」（滑過或聚焦時會出現虛線底線提示可編輯）。
  • 修改後會即時同步到瀏覽器分頁標題。
  • 執行「匯出檢視版」時，這個名稱會一併帶入匯出的網頁（作為檢視版的標題與分頁名稱）；在檢視版中標題為唯讀顯示，不可再編輯。

畫面說明

  • 時間軸為橫向，事件卡片依日期先後等距排列、一路往右延伸；年份差距不會拉開間距。
  • 年份顯示在時間軸橫線的上方，對齊該年第一個事件的位置；同一年的事件會聚成一段淡色色帶。
  • 角色生日以菱形標記在軸線上（可在工具列開關）。
  • 在時間軸的空白處（卡片以外）按住滑鼠左鍵可左右拖曳平移畫面；按在卡片、按鈕、連結、輸入框上則維持原本操作。也可用捲軸或觸控滑動。
  • 事件卡片一律排在軸線下方，由上而下的內容順序為：
    1. 類型（上方小標）
    2. 標題
    3. 日期
    4. 關聯角色（緊接日期下方，以角色代表色小標籤呈現）
    5. 說明
    6. 註記（追加備註，多筆用「|」分隔；12px 小字、前綴「▸」逐筆顯示，與說明明顯區別）
    7. 連結
    8. 小記按鈕（若該事件有填短篇故事才顯示；點擊以頁內視窗閱讀，內文最後可含後記，後記標題為🖋️）
    9. 全部角色的當時年齡（卡片最下方，以虛線分隔）
  • 卡片顏色：左側色條是所有關聯角色代表色的漸層（單一角色則為純色）；軸線圓點、連接線，以及卡片上的類型、連結圖示與註記「▸」標記，則使用這些代表色混出的中間色。
  • 標題過長會截斷，游標停在標題上會顯示完整文字。

編輯事件（就地編輯）

  • 點工具列的「新增事件」會新增一張卡片並直接進入編輯狀態。
  • 每張卡片右上角有鉛筆鈕，點下即在該卡片內編輯：標題、類型、年份模式與年月日、關聯角色、說明、註記、連結、小記、後記。
  • 編輯中的卡片會自動加寬；底部有「刪除此事件」，頂部有「完成」。

角色

  • 工具列「角色」面板可新增／修改／刪除角色，並設定名稱、生日（年份模式＋年月日）、代表色。
  • 事件的「關聯角色」是以角色名稱對應；若更改角色名，記得一併更新相關事件的關聯。

年份模式（相對／絕對）

  • 相對：架空紀年「第 N 年」（年填 1、2、3…）。
  • 絕對：西元年。
  • 若同時混用兩種紀年，請用工具列「第一年＝西元」設定把兩者對齊到同一條軸；純用一種時可忽略。
  • 「年份標籤」可選擇顯示為「第 N 年」「西元」或「自動」。

顯示設定

  • 間距：調整事件卡片之間的水平距離（越小越密；過小會自動往下疊成多排）。
  • 字級：全域字級（最小 13px）。註記為固定 12px（不隨此設定縮放），是全站唯一低於 13px 的文字。
  • 生日：開關軸線上的生日菱形。

CSV 匯入／匯出

工具列「CSV」面板可用文字或檔案批次編輯資料，並與卡片共用同一份資料。按「套用 CSV」會以文字框內容整批取代目前資料。

角色 CSV 欄位

角色, 年份模式, 年, 月, 日, 顏色

  • 年份模式：填「相對」或「絕對」（也接受 rel／abs）。
  • 月、日可留空。顏色為十六進位色碼，如 #2f6fb0。

事件 CSV 欄位

事件, 類型, 年份模式, 年, 月, 日, 角色, 說明, 註記, 連結, 小記, 後記

  • 類型：自由填寫，如「日常」「劇本名稱」。
  • 角色（關聯）：可多個，用「、」分隔，例如 艾德里安、露娜。（請勿用半形逗號，會被當成 CSV 欄位分隔。）
  • 說明：可換行，會照原樣顯示。
  • 註記：事件的追加備註，多筆用 | 分隔，例如 備註一|備註二；在卡片上以 12px 小字（前綴「▸」、較淡顏色）逐筆顯示，與說明有所區別。
  • 連結：每筆寫成 名稱,網址，多筆用 | 分隔，例如 維基,https://…|設定集,https://…。（以第一個逗號切分名稱與網址，網址內含逗號也不會被誤切。）
  • 小記：短篇故事（可換行）。有填寫時卡片會出現「閱讀小記」按鈕，點擊以頁內視窗閱讀；留空則不顯示按鈕。
  • 後記：顯示於「小記」內文最後的後記（可換行），在閱讀視窗中以分隔線隔開、以筆的圖示（🖋️）標示、並以斜體淡色呈現。

連結

卡片上的連結一律**開新視窗（新分頁）**檢視。

匯出檢視版 HTML

工具列「匯出檢視版」會下載 char-timeline-view.html，內含目前所有資料、顯示設定與自訂的網頁名稱，但完全無法編輯（沒有新增、編輯、刪除、CSV 匯入等功能），適合分享或放到網站上。

保存與注意事項

  • 資料只存在目前這個網頁分頁，重新整理或關閉後不會保留；請用 CSV 面板的「下載」保存，日後再「上傳＋套用 CSV」還原。（自訂名稱不會存進 CSV，重新整理後會回到預設，若要保留請改用「匯出檢視版」。）
  • 以「檔案總管點兩下」方式開啟（file://）時，瀏覽器可能限制「複製到剪貼簿」；若複製沒反應，改用「下載」即可。
  • 要放到網路上分享，可將 HTML 檔上傳到任何靜態網頁空間（如 GitHub Pages、Netlify）。
